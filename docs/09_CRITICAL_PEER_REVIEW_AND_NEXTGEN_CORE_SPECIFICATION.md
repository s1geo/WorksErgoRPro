### 1.2. Что категорически требует улучшения и рефакторинга
В текущем ядре заложен ряд принципиальных упрощений, которые отделяют его от полноценного промышленного пакета:

1. **Проблема одиночной позы (Single-Pose Limitation):**
   - *Дефект:* Сейчас ядро вычисляет единственную детерминированную позу по трем геометрическим стилям (Stoop, SemiSquat, DeepSquat).
   - *Требование Work(s):* Генератор InteliPose™ сканирует конфигурационное пространство ($10^4\dots 8.5\cdot 10^4$ поз), отсекает коллизии и нарушения ROM, а затем с помощью неравенства ДКВ (DKW 1956) формирует выборку из $n \approx 738$ поз и вычисляет 25-й перцентиль риска.
   - *Решение Next-Gen:* Внедрение оптимизационного решателя FABRIK / QP-IK, минимизирующего суставное утомление и рывок (Flash-Hogan Minimum Jerk), с опцией генерации вариативного облака поз.
2. **2D-упрощение поясничного момента L5/S1:**
   - *Дефект:* В `ErgonomicMathEngine.cs` сжатие L5/S1 рассчитывается в сагиттальной плоскости по моменту сгибания $M_{\text{flex}}$ с константным плечом мышц $0.0585\text{ м}$.
   - *Требование Work(s):* При асимметричных подъемах со скручиванием ($\theta_{\text{twist}}$) и боковым наклоном ($\theta_{\text{lat}}$) эквивалентное плечо мышц $EMA$ обязано рассчитываться по 3D-полиному 3-го порядка:
     $$F_{\text{muscle}} = \frac{\sqrt{M_{\text{flex}}^2 + M_{\text{lat}}^2 + M_{\text{twist}}^2}}{\text{EMA}(M_{\text{flex}}, M_{\text{lat}}, M_{\text{twist}})}$$
3. **Усеченная база хватов HandPak:**
   - *Дефект:* В коде определены только 4 базовых типа хвата (`PowerGripMedial`, `PowerGripLateral`, `PinchGrip`, `PalmPush`).
   - *Требование:* Полная матрица из 23 интерфейсов HandPak с параметрами диаметра рукоятки ($15\dots 50\text{ мм}$), коэффициентов трения материалов (резина $0.65$, сталь $0.35$, гладкий пластик $0.25$) и поправки на рабочие перчатки (снижение силы на 15–20%).
4. **Квазистатика ($a = 0$):**
   - *Дефект:* Ни текущий наш код, ни оригинальный Work(s) Ergo не учитывают динамических перегрузок $F = ma$. При отрыве тяжелого ящика от пола ускорение рук и корпуса дает всплеск компрессии на 30–60% выше статики (Kingma et al. 1996, Lavender et al. 2003).
   - *Решение Next-Gen:* Рекурсивный алгоритм Ньютона — Эйлера (RNEA, Featherstone 2008) для покадрового расчета сил инерции вдоль сплайн-траектории движения в Р-Про.
5. **Отсутствие промышленных европейских стандартов (EAWS):**
   - В автомобилестроении (BMW, VW, Stellantis) отчет без баллов EAWS (European Assessment Worksheet) не принимается службой охраны труда. Необходимо добавить автоматический расчет таблицы EAWS (Section 1–4).

## 2. Спецификация модулей модернизированного ядра

### Модуль 1. 3D-полином эквивалентного плеча рычага L5/S1 (`Spine3DPolynomialSolver`)
```csharp
public static double CalculateEMA(double mFlex, double mLat, double mTwist)
{
    // Регрессионная поверхность 3-го порядка (Potvin, Jäger 2023)
    // Входные моменты в Нм, результат в метрах
    double mRes = Math.Sqrt(mFlex * mFlex + mLat * mLat + mTwist * mTwist);
    if (mRes < 5.0) return 0.0585; // Базовое плечо покоя (58.5 мм)

    double normFlex = mFlex / mRes;
    double normLat = Math.Abs(mLat) / mRes;
    double normTwist = Math.Abs(mTwist) / mRes;

    // Коактивация косых мышц живота при скручивании уменьшает эффективное плечо
    double ema = 0.0585 - (0.012 * normTwist) - (0.008 * normLat) + (0.004 * normFlex);
    return Math.Max(0.038, Math.Min(0.065, ema));
}
```

### Модуль 2. Статистический редуктор выборки ДКВ (`DKWSampler`)
```csharp
public static int CalculateRequiredSampleSize(double epsilon = 0.05, double alpha = 0.05)
{
    // Dvoretzky-Kiefer-Wolfowitz Inequality: n >= ln(2/alpha) / (2 * epsilon^2)
    double numerator = Math.Log(2.0 / alpha);
    double denominator = 2.0 * epsilon * epsilon;
    return (int)Math.Ceiling(numerator / denominator); // 738 поз
}
```

### Модуль 3. Промышленный модуль EAWS (`EawsAssessmentEngine`)
Расчет баллов Европейского опросника:
* **Секция 1 (Рабочие позы):** Баллы за наклон торса ($>20^\circ \implies 3$ б., $>60^\circ \implies 10$ б.), работу с поднятыми руками ($>60^\circ \implies 6$ б.), присед/колени ($>60^\circ \implies 8$ б.).
* **Секция 2 (Действующие силы):** Силы пальцев и рук.
* **Секция 3 (Ручное перемещение грузов):** Подъем/перенос с учетом частоты и массы.
* **Секция 4 (Верхние конечности):** Монотонность и частота действий.
* **Интерпретация:** $\le 25$ баллов — Зеленый, $26\dots 50$ — Желтый, $> 50$ — Красный.
