Выбор свойств в компоненте 

Вам нужно использовать панель Диаграмма компонента для выбора свойств в компоненте. Когда свойство выбрано, его свойства будут отображаться на панели задач Свойства. В противном случае любые видимые свойства компонента могут быть прочитаны и отредактированы на панели Свойства при выборе компонента или его корневого узла.

1.В трехмерном мире выберите компонент.

2.Если вы не выбрали функцию, щелкните вкладку Моделирование, а затем в панели Диаграмма компонента, Дерево узлов компонента, разверните корневой узел.

3.Если свойства не перечислены ниже корневого узла, установите флажок Свойства.

4.Разверните список Свойств, чтобы найти свойство, которое вы хотите выбрать, а затем щелкните это свойство. Альтернативой является поиск свойства по имени с помощью поля поиска.
