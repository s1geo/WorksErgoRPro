Создание операторов в программе робота 

Оператор — это команда, выполняемая роботом в своей программе.

Операторы в программе робота содержатся в подпрограммах и выполняются по порядку один за другим. Явные переменные и другие свойства робота, включая порты ввода-вывода, могут использоваться для определения операторов и условий выполнения программы.

1.Нажмите на вкладку Программирование, а затем выберите робота в трехмерном мире, которого вы хотите запрограммировать.

2.На панели Редактор программы, создайте или выберите подпрограмму.

3.Если вам будет предложено обновить исполнитель выбранного робота, нажмите Обновите исполнитель Rsl, а затем вернитесь к шагу 2.

4.На панели инструментов Операторы, сделайте одно из следующих действий:

·Чтобы создать движение от точки к точке к текущему положению робота, нажмите Движение от точки к точке. *

·Чтобы создать линейное движение к текущему положению робота, нажмите Линейное движение. *

·Чтобы сгенерировать путь позиций вдоль края или кривой, нажмите Движение по траектории.* Отобразится панель задач «Выбрать кривую» для выбора и редактирования траектории точек, например швов в заготовке. Сгенерированные точки являются операторами линейного движения и вложены в оператор Path.

·Чтобы обновить инструментальную рамку во время симуляци, нажмите Определить инструмент, а затем определите значения для рамки инструмента, установленного этим оператором.

·Чтобы обновить базовый кадр во время симуляци, нажмите Определить базу, а затем определите значения для рамки базы, заданного этим оператором.

·Чтобы обновить выбранный оператор PTP или LIN в программе робота, нажмите Обновить положение.

·Чтобы вызвать подпрограмму, нажмите Вызов подпрограммы, а затем определите подпрограмму, вызываемую этим оператором.

·Чтобы присвоить переменной значение, нажмите Присвоить переменной.

·Чтобы создать цикл, нажмите Пока, а затем определите условие выполнения операторов, вложенных в этот цикл.

·Чтобы завершить выполнение цикла, нажмите Break.

·Чтобы настроить выполнение цикла со следующей итерации, нажмите Continue.

·Чтобы создать условный оператор, нажмите Если (If), а затем определите условие для выполнения операторов, вложенных в группу THEN или ELSE этого оператора.

·Чтобы создать условный оператор, нажмите Переключатель Случаев (Switch-Case), а затем определите условие для выполнения операторов и добавьте вложенные случаи.

·Чтобы завершить выполнение подпрограммы, нажмите Return.

·Чтобы синхронизировать выполнение программы с другими компонентами, нажмите Оператор синхронизации программы, а затем определите сообщение и компоненты для синхронизации, а также определите, будет ли инструкция ожидать, пока все компоненты в синхронизации отправят правильное сообщение, прежде чем продолжить выполнение программы.

·Чтобы отложить выполнение подпрограммы, нажмите Задержка, а затем определите задержку в секундах для этого оператора.

·Чтобы остановить выполнение подпрограммы, нажмите Остановка, а затем определите, будет ли эта инструкция сбрасывать симуляцию.

·Чтобы оставить комментарий, нажмите Комментарий, а затем определите комментарий для этого утверждения.

·Чтобы показать сообщение в выводе, нажмите Печать, а затем определите сообщение для этого оператора.

·Чтобы дождаться, пока входной сигнал будет иметь определенное значение, нажмите Ожидать бинарный вход, а затем определите значение и номер порта для ожидания в этом операторе.

·Чтобы установить значение выходного сигнала, нажмите Установить бинарный выход, а затем определите состояние и номер порта для этого оператора.

·Чтобы задать состояние робота для статистики, нажмите Установить состояние.

* Подсказка: Кроме того, вы также можете использовать действия в меню Teach Overlay.Смотрите Быстрое обучение траектории роботов
