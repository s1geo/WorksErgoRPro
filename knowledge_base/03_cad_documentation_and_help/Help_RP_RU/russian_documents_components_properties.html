Свойства

Свойство — это глобальная переменная в компоненте. Свойства содержатся в корневом узле компонента. Любые видимые свойства выбранного компонента в трехмерном мире будут отображаться на панели свойств.

Распределение

Псевдослучайное вещественное число, сгенерированное выражением, определяющим распределение.

normal([stream], u, s) - Нормальное распределение среднего значения u и стандартное отклонение s с дополнительным stream для заполнения случайного значения в генератор.

exponential([stream], lambda) - Экспоненциальное распределение, где среднее значение 1/lambda и дисперсия 1/lambda^2 с дополнительным stream для заполнения случайного значения в генератор.

gamma([stream], k, theta) - Гамма-распределение с формой k и масштаб theta с дополнительным stream для заполнения случайного значения в генератор

lognormal([stream], u, s) - Логарифмическое нормальное распределение для среднего значения u и стандартное отклонение s с дополнительным stream для заполнения случайного значения в генератор

triangular([stream], min, mode, max) - Треугольное распределение для заданных значений min, mode и max с необязательным stream для заполнения случайного значения в генератор

uniform([stream], a, b) - Равномерное распределение по диапазону а <= х < b с дополнительным stream для заполнения случайного значения в генератор

weibull([stream], k, lambda) - Распределение Вейбулла с формой k и масштабом lambda с необязательным stream для заполнения случайного значения в генератор

Общие свойства

Все свойства на уровне компонентов являются объектами, которые имеют собственный набор свойств для определения того, как получить доступ к свойству и прочитать/записать его значение.

Название

Описание

Наименование

Определяет имя свойства.

Имя свойства можно использовать для назначения свойства вкладки на панели Свойства. Синтаксис [TabName]::[PropertyName] . Если вкладка не существует, будет создана новая вкладка, которая будет отображаться до тех пор, пока самой вкладке будут назначены видимые свойства; в противном случае вкладка будет скрыта. По умолчанию свойства назначаются вкладке Default, которая четко обозначена, когда на панели свойств отображаются две или более вкладок.

Видимый

Включает/выключает отображение свойства на панели свойств.

При изменении значения

Запускает событие и набор действий при изменении значения свойства.

Перестроить

Перестраивает геометрию компонента и пересчитывает выражения. Как правило, вам нужно включить Перестроить только в том случае, если свойство используется с элементами или выражениями в узле. В противном случае Перестроить является ненужным действием.

Обновить симуляцию

Обновите трехмерный мир (корневой узел симуляции), чтобы показать текущее состояние компонента на основе значения свойства. Как правило, обновление симуляции требуется для настройки соединения или обновления изменений, внесенных в компонент во время симуляции.

Разрешить редактирование, когда

Определяет правила установки значения свойства.

Отключен

Позволяет редактировать свойство, когда компонент не подключен ни к какому другому компоненту.

Связано

Позволяет редактировать свойство, когда компонент подключен к любому другому компоненту.

Симулирование

Позволяет редактировать свойство во время моделирования.

Значение

Определяет значение свойства.
