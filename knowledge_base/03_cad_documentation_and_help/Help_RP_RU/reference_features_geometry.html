Геометрия

Объект Геометрия — это контейнер геометрии, который либо импортируется, либо генерируется в объекте, либо сворачивается из других объектов.

Элементы геометрии можно использовать для загрузки взаимозаменяемой геометрии, и они являются контейнером по умолчанию для импортированной геометрии.

Свойства

Название

Описание

Наименование

Определяет наименование элемента.

Видимый

Включает/выключает видимость элемента и ее подэлементов.

Uri

Определяет путь к файлу САD, загружаемому элементу. Изменение пути к файлу удаляет всю ранее существовавшую геометрию в элементе.

ЗагрузкаПоЗапросу

Включает/выключает выделение памяти для содержащейся геометрии в зависимости от необходимости элемента. Как правило, ЗагрузкаПоЗапросу используется, когда имеется большое количество геометрии, а элемент Switch контролирует использование этой функции.

ПоказатьЗадниеГрани

Включает/выключает отрисовку обратных сторон в объекте.

УголСкладки

Определяет допуск угла для обработки смежных граней как одной гладкой поверхности во время расчетов освещения, в которых нормали граней усредняются для получения нормалей отражения.

Выбираемый

Определяет, можно ли выбрать геометрию объекта в 3D-мире. Это влияет на любой инструмент, команду или ярлык, которые используют типы привязки.

Физика

Определяет набор физических свойств объекта.
