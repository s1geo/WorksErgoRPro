Цилиндр

Цилиндрический элемент представляет собой цилиндрическую форму.

Цилиндры представляют собой гибкие формы, из которых можно формовать множество различных объектов.

Свойства

Название

Описание

Наименование

Определяет наименование цилиндра.

Видимый

Включает/выключает видимость цилиндра.

Материал

Определяет материал цилиндра.

Радиус

Определяет радиус цилиндра.

Высота

Определяет высоту цилиндра по оси Z.

НачалоРазвертки

Определяет начальный угол (в градусах) охвата поверхности цилиндра.

КонецРазвертки

Определяет конечный угол (в градусах) охвата поверхности цилиндра.

Секции

Определяет количество секций, созданных для окружности цилиндра. Низкое значение может создать призму.

Кэпы

Включает/выключает отрисовку колпачков в цилиндре.

Физика

Определяет набор физических свойств объекта.
