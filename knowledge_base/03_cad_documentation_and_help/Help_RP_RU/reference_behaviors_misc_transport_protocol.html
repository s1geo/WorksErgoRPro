Транспортный протокол

Транспортный протокол позволяет обрабатывать действия по транспортировке, запрашиваемые ресурсами, с помощью скрипта Python.

Свойства

Название

Описание

Наименование

Определяет наименование протокола.

Статистика

Определяет поведение статистики, которое собирает статистику, созданную протоколом.

Вместимость

Определяет количество компонентов, которые транспортный контейнер может содержать в любой момент времени.

БлокиЕмкости

Определяет список вариантов поведения контроллера емкости для глобального определения емкости транспортного контейнера. Как правило, контроллер емкости используется в качестве переменной для управления емкостью одного или нескольких контейнеров, чтобы избежать тупиковых ситуаций.

СигналПерехода

Определяет поведение логического сигнала, которое сигнализирует о прибытии и отправлении компонентов в транспортный контейнер и из него. Значение True сигнализирует о прибытии компонента. Значение False сигнализирует об уходе компонента.

Ресурсное обеспечение

Определяет поведение, используемое протоколом для управления транспортными задачами. В большинстве случаев вы будете использовать контейнер действий (Action Container).
