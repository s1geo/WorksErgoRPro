Исполнитель процесса

Исполнитель процесса содержит одну или несколько подпрограмм процесса, которые он может выполнять. Выполнение процесса запускается автоматически при запуске симуляции и продолжает выполняться во время симуляции, если оно не остановлено намеренно.
