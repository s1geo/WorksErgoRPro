Проверить траекторию

Робот может послать, в своей программе, выходной сигнал, который запускает трассировку объемом. По умолчанию сигнал 81 в роботе предназначен для выполнения этого действия.

Трассировка объемом

Это процесс, заключающий геометрию в выпуклую оболочку для создания профиля. Затем этот профиль или объем геометрии можно многократно генерировать от начала и до конца его движения.

Если профиль не перемещается, вы будете создавать его геометрию на каждой итерации в одном и том же пространстве. Если профиль перемещается, вы будете создавать его геометрию на каждой итерации вдоль траектории движения.

Методы

Метод генерации развертки определяет его точность.

·Lofting хорош для движений, требующих небольших изменений.

·Hull from Hulls поддерживает все типы движений, но дает больше данных.

·Hull from Silhouettes представляет собой баланс двух других методов и поддерживает простые и сложные движения.

Хранилище

Во всех случаях вы должны содержать охватываемый объем в узле, который не перемещается во время симуляции. В противном случае движение этого узла повлияет на охватываемый объем. Узел может находиться либо в:

·Выбранном узле (компоненте).

·В компоненте, обнаруженным сигнальным объемом инструмента робота.

·Новый компонент, который создается при первом симулировании действия.

Трассировка объемом может быть постоянно сохранена в компоненте или удалена из 3D-мира при сбросе симуляции.

Настройка действия

1.В 3D-мире выберите робота.

2.На панели Свойства, развернуть раздел Конфигурация действий.

3.Под Сигнальные действия, сделайте одно из следующих действий:

·Чтобы настроить новое действие, установите в Вывод любой сигнал больше 81, а затем установите На Истинном - Трассировка Объемом Включена.

·Чтобы настроить существующее действие, установите в Вывод сигнал 81, или сигнал который вы уже настроили для выполнения развертки.

4.Под параметром Трассировка Объемом Включена, выполните все следующие действия:

·Чтобы определить метод, который будет использоваться для генерации охвата, установите Метод трассировки к нужному варианту.

·Чтобы определить геометрию и профиль развертки, установите Геометрия трассировки для включения узлов, содержащих желаемую геометрию. Вы можете включить любой узел из 3D-мира, но сначала вам нужно развернуть Геометрия трассировки, а затем использовать либо кнопку Выбрать, чтобы напрямую выбрать узел в 3D-мире, либо кнопку Добавить, чтобы выбрать узел из списка. Порядок узлов, перечисленных в Геометрии трассировки, не влияет на действие.

·Чтобы определить материал рабочего объема, установите нужный вариант в Материал. Если материал не выбран, материал по умолчанию имеет желтый цвет. Действие не может использовать несколько материалов, учитывая его текущую реализацию, но вы можете сделать это с помощью API, см. vcSweptVolume .

·Чтобы определить режим для прикрепления развертки, установите Прикрепить к в нужный параметр.

·Если Node, Выберите Целевой узел, в котором будет находиться развертка.

·Если Closest, определите, какую рамку инструмента в роботе вы хотите использовать и какую область обнаружения вы хотите создать в системе координат рамки инструмента для обнаружения близлежащего узла. Эта опция исключит все узлы робота.

·Если New Component, компонент будет добавлен в трехмерный мир при первом симулировании действия. Если вы не сохраняете анализируемый объем, вы можете использовать панель Дерево построения, чтобы выбрать добавленный компонент.

5.Под параметром Трассировка Объемом Выключена, сделайте одно из следующих действий:

·Чтобы сохранить анализируемый объем, установите флажок Сохранить геометрию. Охватываемый объем, созданный этим действием, не будет удален из трехмерного мира при сбросе симуляции.

·Чтобы не сохранять анализируемый объем, снимите флажок Сохранить геометрию. Охватываемый объем, созданный этим действием, будет удален из трехмерного мира при сбросе симуляции.

Симуляция Действия

1.Нажмите на вкладку Программирование, а затем используйте команду Взаимодействие для выбора робота в 3D-мире.

2.На панели Редактор программы, выберите процедуру, а затем добавьте оператор Установить бинарный выход.

3.На панели Свойства выражения, выполните все следующие действия:

·Установите Выходной порт соответственно сигналу в роботе, сконфигурированном для действия с разверткой.

·Установите Выходное значение на Истинное, чтобы включить создание анализируемого объема во время выполнения программы. В большинстве случаев действие должно быть настроено таким образом, чтобы значение True включало сканируемый объем, а значение False отключало сканируемый объем.

4.На панели Редактор программ можете измените положение этого оператора, как это необходимо в подпрограмме. Например, вы можете захотеть, чтобы действие запускалось до того, как робот переместится в определенные позиции.

5.Повторите шаги со 2 по 4, но на этот раз установите Выходное значение на Ложное, чтобы отключить создание анализируемого объема.

6.Запустите симуляцию, чтобы выполнить трассировку.
