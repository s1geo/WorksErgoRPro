Поиск данных компонента 

В верхней части каждой панели панели Диаграмма компонента находятся инструменты для поиска и фильтрации данных в выбранном компоненте.

1.В трехмерном мире выберите компонент.

2.Перейдите на вкладку Моделирование, а затем на панели Диаграмма компонента выполните одно из следующих действий:

·Чтобы свернуть все в дереве, нажмите кнопку Свернуть (ЗНАК МИНУС).

·Чтобы развернуть все в дереве, нажмите кнопку Развернуть (ПЛЮС).

·Для поиска элементов в дереве используйте Поле поиска. Поле поиска в дереве узлов компонентов можно использовать для поиска узлов, поведения и свойств. Поле поиска в дереве элементов узла можно использовать для поиска элементов в выбранном узле.

·Чтобы отобразить/скрыть все варианты поведения в дереве узлов компонентов, используйте флажок Поведение.

·Чтобы отобразить/скрыть все свойства в дереве узлов компонентов, используйте флажок Свойства.
