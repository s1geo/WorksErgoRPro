Отправить сигнал

Оператор Отправить сигнал  позволяет инициировать поведение сигнала с заданным значением. Вы можете выбрать Логический, Целочисленный, Вещественный, Строковый или Компонентный сигнал из любого статического компонента на планировке симуляции.

Свойства

Название

Описание

Компонент

Компонент, которому принадлежит сигнал. Null означает этот компонент.

Сигнал

Сигнал для отправки.

Значение

Выражение для генерации значения сигнала. Можно ссылаться, например, на статические свойства или свойства в динамических продуктах.

Смотрите также Выражения оператора процесса .
