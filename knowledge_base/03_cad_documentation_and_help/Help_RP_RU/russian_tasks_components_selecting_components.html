Выбор компонентов

Выделение в 3D-мире выделяется Силуэтом и Заливкой.

В трехмерном мире можно:

·Нажать на любой компонент, чтобы выбрать его.

·Удерживая нажатой клавишу CTRL, нажать на компоненты, чтобы добавить или удалить их из выделения.

·Нажать на пустое место в 3D-мире, чтобы снять выделение.

При нажатии на компонент в 3D-мире на короткое время появляется мини-панель инструментов, содержащая опции для выполнения быстрых действий.
