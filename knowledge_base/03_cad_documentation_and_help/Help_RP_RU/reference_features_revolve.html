Вращать

Элемент Вращать перемещает геометрию дочерних элементов вдоль пути, тем самым создавая новую геометрию.

Как правило, операция «Вращение» используется для сдвига геометрии, что иногда требует использования элементов «Преобразовать» и «Выдавливание».
