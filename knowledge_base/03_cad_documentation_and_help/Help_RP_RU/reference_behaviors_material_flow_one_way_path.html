Односторонний путь

Односторонний путь позволяет вам содержать и перемещать компоненты вперед по пути, определенному элементами системы координат.

 

Порты одностороннего пути перечислены вместе с поведением на панели Диаграммы Компонентов.

Свойства

Название

Описание

Наименование

Определяет наименование пути.

Статистика

Определяет поведение статистики, которое собирает статистику, сгенерированную путем.

Вместимость

Определяет количество компонентов, которые может содержать путь в любой момент времени.

Блоки емкости

Определяет контроллер емкости для глобального определения емкости пути. Как правило, контроллер емкости используется в качестве переменной для управления емкостью одного или нескольких контейнеров, чтобы избежать тупиковых ситуаций.

СигналПерехода

Определяет поведение логического сигнала, которое сигнализирует о прибытии и уходе компонентов на путь и с пути. Значение True сигнализирует о прибытии компонента. Значение False сигнализирует об уходе компонента.

Скорость

Определяет скорость, с которой компоненты перемещаются по пути. Чтобы позволить компонентам обгонять друг друга, вам необходимо переопределить скорость пути с помощью скрипта Python.

Ускорение

Определяет максимальное ускорение для движущихся компонентов по траектории. Нулевое значение отключает ускорение пути.

Замедление

Определяет максимальное замедление для движущихся компонентов по траектории. Нулевое значение отключает замедление пути.

Интерполяция

Определяет режим управления поведением пути при перемещении компонентов.

Шаг - Привязывает компоненты к путевым точкам и от них с интервалом времени (линейное расстояние пути, деленное на скорость пути).

Линейное движение - Перемещает компоненты к путевым точкам и от них по прямой линии.

Кубическая кривая - Перемещает компоненты к путевым точкам и обратно по цепочке кубических сплайнов, например, по криволинейному пути. Как правило, кривизна пути более определена, когда путь имеет большее количество путевых точек (элементов Системы координат).

Аккумулирование

Определяет, отключается ли путь, когда выход компонента заблокирован. Значение True останавливает путь. Значение False не останавливает путь.

РазмерСегмента

Определяет длину и использование сегментов пути. Например, если линейное расстояние пути составляет 1000 {мм}, РазмерСегмента равный 100, формирует 10 сегментов и ограничивает перемещение компонентов в каждый сегмент и из него. То есть по одному компоненту на сегмент. Нулевое значение отключает использование сегментов.

СохраненитьСмещение

Включает/выключает способность компонента сохранять свое положение при входе в путь. Например, партия компонентов, случайно размещенная по ширине конвейерной ленты, может сохранять свое распределение, а не привязываться к линии пути.

ИспользованиеПространства

Включает/выключает наложение компонентов на пути. Значение True означает, что компоненты могут граничить друг с другом, но не обгонять друг друга в одном и том же сегменте пути. Значение Fale означает, что компоненты могут располагаться рядом друг с другом и перекрываться.

ИспользованиеПространства не влияет на индексирование компонентов пути. Таким образом, значение False не означает, что компоненты будут обгонять друг друга в списке. Вы можете использовать скрипт Python для управления индексацией для буферизации, укладки в стек, маршрутизации и т. д.

БыстроеПланирование

Включает/выключает оптимизацию движущихся компонентов по траектории. Если значение равно True, путь ограничивает количество генерируемых событий, тем самым повышая производительность симуляции. Если False, путь перемещает компоненты с более коротким шагом, тем самым увеличивая количество событий и снижая производительность симуляции.

Примечание : вам необходимо включить эту опцию вручную в компонентах, созданных с помощью более старых версий продукта.

Датчики

Определяет список поведений, связанных с путем и используемых для обнаружения компонентов на траектории. Каждое поведение должно относиться к типу датчик и определять его местоположение относительно траектории, например, расстояние от датчика вдоль траектории или одна из рамок траектории.

Путь

Определяет упорядоченный список систем координат элементов в компоненте пути, которые действуют как путевые точки пути. Последовательность точек важна при определении начала и конца пути.

ОсьТраектории

Определяет ориентацию точек пути относительно расчетной оси.

автоматический режим - Использует ориентацию каждой путевой точки для расчета соответствующей оси. Общий будет использоваться, если путевые точки значительно различаются по ориентации.

Х-положительная ось  - Использует расстояние от начала координат компонента пути до положительного предела по оси X граничной системы координат этого компонента.

Y-положительная ось - Использует расстояние от источника компонента пути до положительного предела по оси Y граничной системы координат этого компонента.

Z-положительная ось - Использует расстояние от источника компонента пути до положительного предела по оси Z граничной системы координат этого компонента.

X-отрицательная ось - Использует расстояние от начала координат компонента пути до отрицательного предела по оси X граничной системы координат этого компонента.

Y-отрицательная ось - Использует расстояние от начала координат компонента пути до отрицательного предела по оси Y граничной системы координат этого компонента.

Z-отрицательная ось - Использует расстояние от начала координат компонента пути до отрицательного предела по оси Z граничной системы координат этого компонента

Общий режим - Использует оценку наихудшего случая, основанную на граничной системе координат этого компонента.
