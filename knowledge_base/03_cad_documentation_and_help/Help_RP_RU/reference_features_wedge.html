Призма 

Элемент Призма представляет собой клиновидную форму.

Призмам можно придать различную форму, длину и высоту, а также зеркально отразить по разным осям.

Свойства

Название

Описание

Наименование

Определяет наименование Призмы.

Видимый

Включает/выключает видимость Призмы.

Материал

Определяет материал Призмы.

БольшаяДлина

Определяет нижнюю длину Призмы по его оси X.

МеньшаяДлина

Определяет верхнюю длину Призмы по его оси X.

БольшаяВысота

Определяет заднюю высоту Призмы по его оси Z.

МеньшаяВысота

Определяет высоту переднего края Призмы по его оси Z.

Ширина

Определяет ширину Призмы по оси Y.

ОтзеркаливатьНазад

Включает/выключает зеркальное отражение Призмы по его отрицательной оси Y.

ОтзеркаливатьВниз

Включает/выключает зеркальное отражение Призмы по его отрицательной оси Z.

Физика

Определяет набор физических свойств объекта.
