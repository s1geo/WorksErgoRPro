Шарнирная кинематика

Поведение шарнирной кинематики — это список кинематических свойств, используемых контроллером робота для решения движений сочлененного робота, которые связаны с длиной соединения, углом, положением, соединением, конфигурацией и допусками.

НулевоеСмещениеСоединения1 по НулевоеСмещениеСоединения6

Определяет нулевую позицию соединения робота. НулевоеСмещениеСоединения (JointZeroOffsets) используются в качестве кинематического решения для определения положения робота, когда его суставы имеют нулевое значение (градусы). Различные поставщики роботов, как правило, используют разные совместные нулевые позиции для роботов.

ДопускПолярнойСингулярности

Определяет радиус круга сингулярности робота, небольшого круглого пространства, определяемого на конце руки робота.

ДопускСингулярностиЗапястья

Определяет угловой допуск сингулярности запястья робота. То есть, когда пятый шарнир приближается к нулевому значению, это можно считать сингулярностью, поэтому в таких случаях можно использовать допуск на угол.

РасширенныйДопускПоложения

Определяет значение допуска для обнаружения сингулярности в конфигурации робота, когда либо робот находится в выдвинутом положении, либо его локоть проходит через нулевое значение, чтобы достичь точки. Значение (в градусах) должно быть больше или равно нулю. Если значение равно нулю, то единственного решения нет и, скорее всего, пользователь получает ошибку достижимости. Решение сингулярности или ориентация, основанное на изменениях конфигурации локтя робота для достижения точки, может потребовать от пользователя определения РасширенныйДопускПоложения.

Сцепление456

Определяет связь между 4, 5 и 6 осями. Повороты 5-й и 6-й осей определяются при индуцировании движения по 4-й оси. Это свойство используется редко, а коэффициент связи является дробным и должен предоставляться производителем робота. В противном случае используйте нулевое значение. Сцепление456 необходимо, например, при использовании полого запястья с тройным роликом, когда конструкция механизма обеспечивает соединение между всеми осями.
