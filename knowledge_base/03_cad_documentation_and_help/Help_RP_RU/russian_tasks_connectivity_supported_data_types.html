Поддерживаемые типы данных 

На стороне симуляции вы можете подключить свойства компонентов, сигналы, базы контроллеров и инструменты. Эти переменные симуляции могут быть подключены к внешнему программному обеспечению и устройствам через подключаемые модули.

Функция подключения поддерживает следующие типы переменных симуляции: логическое значение, вещественное число, целое число, строку, матрицу и вектор. Обратите внимание, что рамки инструмента робота и базы также могут быть прочитаны и записаны как матрицы и векторы.

Если тип переменной симуляции и поддерживаемый тип данных подключаемого модуля не совпадают, предпринимается попытка автоматического преобразования данных.

Информация о преобразовании

Matrix

Матрица представляет собой матрицу  размерностью 4x4. Каждое из 16 полей представляет собой 64-битную переменную с плавающей запятой.

Каждая матричная переменная включает в себя положение (P), ориентацию (O) и вектор масштабирования (S).

 

String

Матрицы имеют формат столбца. Преобразование из Matrix в строку всегда использует определенный формат, разделенный запятыми, со всеми 16 значениями.

Строки с 16 значениями определяют все поля матрицы.

Строки с 6 значениями создают матрицу перемещения и поворота (X, Y, Z, W, P, R)

Строки с 3 значениями создают матрицу перемещения (X, Y, Z)

 

Vector

Вектор — это 4-элементный (X, Y, Z, W). Каждое из 4 полей представляет собой 64-битную переменную с плавающей запятой.

String

Строка с одним числовым значением создает вектор X, Y и Z, присваивая им это значение, а для W устанавливается значение 1.

Строки с 2-4 значениями создают вектор X, Y, Z, W присваивая значения в соответствующем порядке. Неназначенные поля остаются в состоянии по умолчанию, которое равно 0 для X, Y и Z и 1 для W.

Преобразование из вектора в строку всегда использует определенный формат, разделенный запятыми, со всеми 4 значениями.

Значение элемента вектора W всегда должно быть равно 1, чтобы вектор оставался нормализованным.

WinMOD

WinMOD позволяет добавлять только три типа данных к своим внешним коммуникационным блокам, которые затем можно читать и записывать с помощью коммуникационной библиотеки WinMOD Net.

Примечание:

·Диапазон масштабирования, используемый для аналоговых сигналов, составляет от -1 000 000 до +1 000 000, что приводит к размеру шага значения около 0,0005. Возможно, вам потребуется соответствующим образом настроить масштабирование подключенных аналоговых сигналов на стороне WinMOD, чтобы получить правильные результаты.
