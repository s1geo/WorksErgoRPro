Информация о взаимодействии

Jog Info позволяет вам сделать объект или свойство интерактивным, определив его степень свободы.

Свойства

Название

Описание

Наименование

Определяет наименование Информации о взаимном движении.

Смещение

Определяет смещение (матрицу) в системе координат содержащего узла.

DOF

Определяет степень свободы Информации о взаимном движении, которая представляет собой перемещение или вращение по определенной оси.

Масштаб

Определяет масштабный коэффициент для взаимодействия, который в большинстве случаев равен ± 1 в зависимости от того, нужно ли инвертировать взаимодействие.

Переменная

Определяет свойство или объект, который Информация о взаимном движении делает интерактивным.

Сообщение

Определяет сообщение, которое будет напечатано, когда вы пытаетесь взаимодействовать с Переменной с помощью команды Interact или Jog.
