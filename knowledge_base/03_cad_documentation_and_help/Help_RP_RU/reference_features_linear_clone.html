Линейный клон

Элемент линейного клонирования клонирует дочерние элементы вдоль оси.

В некоторых случаях операции линейного клонирования объединяются в цепочку для клонирования объектов по двум или более осям.

Свойства

Название

Описание

Наименование

Определяет наименование элемента.

Количество

Определяет, сколько раз клонировать дочерние объекты.

0 скрывает исходные дочерние функции или элементы.

1 показывает исходные дочерние функции или элементы.

n+1 показывает исходные дочерние функции  (или элементы) и n количество клонов.

Шаг

Определяет расстояние между каждым клоном.

Направление

Определяет направление клонирования дочерних элементов.

Физика

Определяет набор физических свойств объекта.
