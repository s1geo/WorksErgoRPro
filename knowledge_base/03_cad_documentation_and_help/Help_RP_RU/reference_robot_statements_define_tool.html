Определить инструмент

Оператор Определить инструмент изменяет свойства системы координат инструмента в роботе во время симуляции. Когда вы сбрасываете симуляцию, система координат инструмента возвращается в исходное положение.

Примечание: Систему координат инструмента можно использовать в качестве центральной точки инструмента (tcp) для операторов движения. Перемещение системы координат инструмента изменит положение робота в конечной точке операторов движения. Как правило, оператор «Определить инструмент» используется в программах роботов, включающих смену установленного инструмента, сварку, обслуживание станка и внешние конфигурации со статическими центральными точками инструмента.

Свойства

Название

Описание

Инструмент

Определяет систему координат инструмента контроллера робота, измененную оператором.

Примечание: Вы не можете использовать оператор Определить инструмент для изменения системы координат инструмента в другом роботе.

IsRelative

Определяет, основана ли позиция на системе координат инструмента или на родительской системе координат.

True использует  систему координат инструмента, поэтому система координат будет перемещена относительно своего местоположения во время выполнения оператора.

False использует относительную систему координат инструмента, определенную в узле, поэтому система координат будет перемещена в абсолютное местоположение.

Position

Определяет положение и ориентацию инструмента.

IPOрежим

Определяет режим интерполяции системы координат и внешнюю конфигурацию контроллера базы робота.

#NONE не имеет никакого эффекта и является настройкой по умолчанию.

#BASE устанавливает  систему координат инструмента в качестве базовой системы координат.

#TCP устанавливает  систему координат инструмента в качестве центральной точки инструмента.

Примечание: Конфликт может возникнуть, если пара «база-инструмент» в референтном роботе имеет одинаковое значение свойства IPOMode или не может использоваться с текущей конфигурацией робота.

УзеNodeл

Определяет узел, к которому прикрепляется система координат инструмента в 3D-мире.
