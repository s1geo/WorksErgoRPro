Переключатель

Элемент Переключатель выбирает один из своих дочерних элементов и отключает другие дочерние элементы.

Операции переключения полезны, если вам нужно отключить геометрию или другие операции на основе свойств компонента.

Свойства

Название

Описание

Наименование

Определяет наименование переключателя.

Выбор

Определяет выражение, которое при оценке выбирает дочерний элемент в зависимости от типа возвращаемого значения.

Логический - Значение True выбирает первый дочерний элемент. Значение False отключает все.

Целое число - Использует индекс, основанный на единице. То есть 1 выбирает первый элемент. Значение 0 не будет выбирать какой-либо дочерний элемент, что, в свою очередь, отключит их все.

Вещественный - Использует индекс с отсчетом от единицы путем округления до ближайшего целого числа меньше его значения. То есть 1.9 выбирает первый элемент.

Строка - Выбирает дочерний объект, имя которого соответствует возвращаемому значению выражения выбора. Если элемент с таким именем не найдена, все отключается.

Физика

Определяет набор физических свойств объекта.
