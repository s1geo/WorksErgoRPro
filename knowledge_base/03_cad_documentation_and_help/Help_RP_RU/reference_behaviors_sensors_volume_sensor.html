Датчик объема

Датчик объема позволяет определить объемное пространство для обнаружения любого компонента в трехмерном мире.

Свойства

Название

Описание

Наименование

Определяет наименование датчика.

ОбновитьСцену

Определяет, обновляется ли мир моделирования (все компоненты) в каждой выборке (время выборки). Для обнаружения движущихся компонентов требуется значение True. И если значение True, для повышения производительности назначьте контейнер обнаружения для обновления только содержащихся в нем компонентов, а не всего мира. В противном случае, для повышения производительности, используйте значение False.

ПроверятьРодительскийУровень

Определяет, обнаруживает ли датчик геометрию в узле, к которому он подключен в трехмерном мире. Как правило, значение True используется для обнаружения самостолкновений, например, дверей в оборудовании, сталкивающихся друг с другом.

ПроверятьСвойУровень

Определяет, обнаруживает ли датчик геометрию в узлах, находящихся на том же уровне, что и датчик в иерархии. Например, компоненты, перемещающиеся по пути, временно присоединяются к узлу пути во время симуляции. Следовательно, датчик можно прикрепить к узлу пути и использовать для обнаружения компонентов, движущихся по пути. В других случаях датчик может содержаться в корневом узле компонента и использоваться для обнаружения других компонентов, присоединенных к 3D-миру (корневой узел симуляции).

ПроверятьТолькоКонтейнер

Определяет, может ли датчик обнаруживать только компоненты, хранящиеся в контейнерах. Как правило, значение True используется для обнаружения компонентов, размещенных в оборудовании и контейнерах для хранения, а также компонентов, уложенных на поддоны.

ПоказатьОбъем

Определяет, визуализируется ли объемное пространство сенсора в трехмерном мире.

МатериалОбъема

Определяет материал объемного пространства датчика. Как правило, используется материал с некоторой прозрачностью или альфа-каналом, чтобы показать область обнаружения и компонент, обнаруженный датчиком.

МетодПроверки

Определяет режим датчика для обнаружения компонентов.

Точный тест  - запускается геометрией компонента, например ребрами и гранями.

BBox Intersect - запускается ограничивающим объемом компонента.

BBox Center Inside - срабатывает, если центр ограничивающего объема находится внутри объемного пространства сенсора.

BBox Fully Inside - срабатывает, если ограничивающий объем компонента полностью находится внутри объемного пространства сенсора.

ИспользоватьИмпульс

Определяет, работает ли датчик с использованием интервала выборки или импульса, управляемого полученным сигналом. Значение True использует режим выборки и дополнительно определяется с помощью ВремяВыборки. Значение False использует импульсный режим, в котором сигнал действует как триггер для обнаружения компонентов. В импульсном режиме свойство Connections поведения типа сигнала имеет датчик, указанный как соединение, и для работы с датчиком используется некоторая итерация, например цикл, написанный в сценарии Python, или некоторая логика, определяющая частоту сигнала.

ВремяВыборки

Определяет временной интервал между каждой выборкой, если ИспользоватьИмпульс включен.

КонтейнерОбнаружения

Определяет, обнаруживает ли датчик только компоненты в указанном контейнере, например путь в компоненте датчика.

СигналКомпонента

Определяет компонентный сигнал, используемый для обозначения того, какой компонент был обнаружен датчиком.

ЛогическийСигнал

Определяет логический сигнал, используемый для подачи сигнала, когда компонент запускает датчик.

Нижняя Рамка

Определяет элемент Рамка, на который ссылается нижний левый угол объемного пространства датчика.

Верхняя Рамка

Определяет элемент Рамка, на которую ссылается верхний правый угол объемного пространства датчика.
