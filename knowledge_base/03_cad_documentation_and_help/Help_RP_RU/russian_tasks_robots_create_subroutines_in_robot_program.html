Создание подпрограмм в программе робота 

Подпрограмма содержит последовательность операторов, которые может выполнить робот. Подпрограммы необходимо вызывать в основной процедуре программы робота либо напрямую, либо с помощью другой подпрограммы, чтобы они выполнялись во время симуляции.

1.Нажмите на вкладку Программирование, а затем используйте Взаимодействие, выберите робота, которого вы хотите запрограммировать в трехмерном мире.

2.На панели Редактор программы возле панели Подпрограммы щелкните ПЛЮС.
