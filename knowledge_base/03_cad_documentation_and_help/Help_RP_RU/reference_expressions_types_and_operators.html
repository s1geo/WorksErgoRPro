Типы и операторы

Тип задает характеристики значения и определяет набор операций, доступных для значения. Операции включают операторы, функции и методы. Типы, имеющие методы, являются сложными и могут содержать атрибуты.

Логические типы

Логический тип представляет собой значение True или False и может быть преобразован в числовой тип. При преобразовании логического значения в числовое True становится равным 1, а False становится равным 0. При преобразовании числового значения в логическое значение 0 становится False, а любое другое число становится True.

Логические операторы

Любой логический оператор вернет логический тип. В синтаксисе выражений нет явных логических литералов, поэтому используйте 1 и 0 для True и False соответственно.

Название

Описание

Логическое НЕ :

!

Унарный префиксный оператор, который инвертирует заданное логическое значение.

!1      ложно

!(1==2)    истинно

Логическое И :

&&

Бинарный оператор, который возвращает True, если оба аргумента имеют значение True. То есть, если первый аргумент равен False, второй аргумент не оценивается.

1 && 1      истинно

0 && z<3    ложно, z<3 никогда не оценивается

Логическое ИЛИ:

||

Бинарный оператор возвращает True, если любой из аргументов истинен. То есть, если первый аргумент имеет значение True, второй аргумент не оценивается.

1 || 0      истинно

1 || z<3    истинно, z<3 никогда не оценивается

Числовые типы

Числовой тип выражает скалярное значение, и большинство из них имеют общие операторы.

Арифметические операторы

Для арифметических операций тип результата зависит от типа каждого аргумента. Если аргументы совпадают, используется общий тип. Если аргументы различаются, используется тип с наибольшим диапазоном. Это изменит поведение некоторых операторов, например деления, когда целочисленное деление выполняется, когда оба операнда являются целыми числами.

Название

Описание

Сложение, вычитание, умножение, деление

+ - * /

Основные арифметические операторы.

1 + 3           4

2 * 5           10

10.0 / 3        3.333333333333333

10 / 3          3  Целочисленное деление

1.0 * 10 / 3    3.333333333333333

Унарный плюс и минус

+ -

Знаковые префиксы.

-1            это -1

-( 3 - 5 )    это  2

Увеличение и уменьшение

++ --

Увеличьте или уменьшите значение на единицу, а затем верните измененное или исходное значение в зависимости от префикса или суффикса переменной.

a = 3, b = ++a    a == 4,  b == 4

a = 3, b = a--      a == 2,  b == 3

Операторы сравнения

Для операторов сравнения результатом всегда будет логическое значение.

Название

Описание

Меньше, меньше или равно, больше, больше или равно

< <= > >=

Сравнивает аргументы, а затем возвращает значение True, если выражение равно True;

3 > 2           результат  true

4 < 3           результат  false

5 <= 2 +3   результат  true

Равно, Неравно

== !=

Оператор равенства возвращает True, если операнды равны; Неравенство является логической противоположностью оператора равенства.

2 + 3 == 5    результат true

3 != 1 + 2    результат false

Операторы присваивания

Название

Описание

Простое присвоение:

=

Присваивает правостороннее значение левостороннему значению, а затем возвращает левостороннее значение после присваивания.

a = 1    результат равен 1, и  a == 1

Изменение присвоения:

+= -= *= /=

Применяет операцию к значениям, затем сохраняет результаты в левом аргументе и, наконец, возвращает левое значение после присваивания.

a += 3    <=> a = a + 3

Тип Целое

Целые числа представлены как 32-разрядные целые числа со знаком и имеют имя типа int. Целые числа могут быть указаны как литеральные значения.

55      десятичный формат

067     ведущий ноль указывает на восьмеричный формат

0x37    шестнадцатеричный формат (допускается также 0X37)

Методы

Целочисленные значения поддерживают следующие операторы в дополнение к стандартным числовым операторам.

Название

Описание

Модуль:

%

Вычисляет остаток от деления между левым и правым аргументами, а затем возвращает это значение.

10 % 3    равно 1

Сдвиг влево, сдвиг вправо:

<< >>

Возвращает значение левого аргумента путем сдвига числа битов, указанного правым аргументом, либо влево, либо вправо.

2 >> 1    равно 1, двоичная 10 сдвигается вправо - 01

1 << 3    равен 8, двоичный код 0001 смещается влево - 1000

Побитовое дополнение:

~

Унарный префиксный оператор, который возвращает 32-битное дополнение своего аргумента.

~0x0000ffff    равно 0xffff0000 отрицательное значение (старший бит указывает знак)

Побитовое И, ИЛИ, XOR:

& | ^

Применяет логику к обоим аргументам, побитно за раз, а затем возвращает результат.

1 & 2          -> 0

1 | 2           -> 3

1 ^ 3           -> 2

Примечание:

·Все поддерживаемые операторы для целочисленного типа, кроме побитового дополнения, существуют как операции присваивания. : %=, <<=, >>=, &=, |= и ^=.

Тип Вещественный

Значения типа Real представлены как 64-битные значения с плавающей запятой IEEE и имеют имя приведения типа double. Вещественные типы могут быть указаны как литеральные значения.

12.4     :целая часть и дробная часть

.63      :присутствует только часть

2.4e6    2400000 целая часть, дробная часть и показатель степени

.8e-3    0.0008 только дробная часть с отрицательным показателем степени

Сложные типы

К сложным типам можно получить доступ или управлять ими с помощью атрибутов и методов, доступ к которым осуществляется с помощью оператора доступа к атрибутам.

vec.X           значение координаты X

vec.Length()    метод, который возвращает длину или абсолютное значение

Основное различие между атрибутами и методами заключается в том, что методы — это функции, принимающие аргументы, тогда как атрибуты просто обращаются к части сложного типа. Как правило, сложные типы поддерживают только небольшое количество операторов.

Тип Матрица

Матрица 4x4 значений типа double с псевдонимом rMatrix. Матрица часто используется для представления позиций в пространстве и линейных преобразований.

Методы

Матрица имеет несколько методов установки или изменения ее значения, и все они могут использоваться как функции. В этом случае функция эквивалентна использованию метода на единичной матрице. Все методы будут возвращать измененную матрицу, поэтому вызовы методов могут быть объединены в цепочку.

Tx(100).Rz(45)    перемещает, а затем вращает матрицу

 

Следующие методы могут быть использованы с матрицей. Единицей для всех угловых параметров являются градусы, если вы не укажете единицу измерения.

Название

Описание

Устанавливает матрицу в соответствии с ее единичной матрицей.

Поворачивает матрицу относительно оси X на заданный угол.

Ry(angle)

Поворачивает матрицу относительно оси Y на заданный угол.

Rz(angle)

Поворачивает матрицу относительно оси Z на заданный угол.

Смещает матрицу по оси X на заданное расстояние.

Ty(distance)

Смещает матрицу по оси Y на заданное расстояние.

Перемещает матрицу по оси Z на заданное расстояние.

IJK(i, j, k)

AxisAngle(i, j, k, angle)

Задает ориентацию матрицы путем поворота единичной матрицы вокруг заданной оси и угла.

Quaternion(q1, q2, q3, q4)

Задает ориентацию матрицы, используя заданные значения кватерниона.

Set(v1, v2, ..., v16)

Устанавливает значения матрицы построчно.

Тип строка

Строка представляет собой последовательность символов с именем приведения rString. Буквенная форма строки заключена в двойные кавычки.

"Hello"         строковый литерал, заключенный в двойные кавычки

"\"Quoted\""    строковая цитата, содержащая заключенные кавычки

Ссылка на тип

Ссылка — это адрес, в котором хранятся переменные и методы объекта. Тип ссылка может хранить следующие типы объектов: Компонент, Узел, Элемент, Поведение, Материал и Параметр.

Ссылка поддерживает оператор доступа к атрибутам для доступа к свойствам объекта.

ref_comp.MyProp        MyProp свойство объекта ссылки

Operators

Название

Описание

Равенство:

Reference == Reference, Reference != Reference

Reference == String,   Reference != String

Сравнивает равенство и неравенство двух ссылок или ссылки и строки. При сравнении ссылки со строкой вместо ссылки используется свойство name ссылки.

Выжанения:

(bool)Reference

(string)Reference

Оператор приведения можно использовать для преобразования ссылочного типа в тип bool и тип string. Значение типа Bool — False, если ссылка имеет значение Null, и True, если ссылка не является Null. Значение строкового типа — это имя объекта.

Список типов

Списки могут содержать только значения одного типа или ссылки на объекты одного типа. Списки также являются строго типизированными, что означает, что тип объекта, на который они ссылаются, известен и не может быть изменен. Если список содержит ссылки, а объект удаляется, ссылка становится Null.

myList[0].Name        Название первого элемента myList
