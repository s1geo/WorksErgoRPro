Конус

Конусный элемент имеет форму конуса/усеченного конуса.

Конусы — это гибкие формы, которые можно моделировать для визуализации пространств, углов обзора, полей и других типов объектов на лету.

Свойства

Название

Описание

Наименование

Определяет наименование конуса.

Видимый

Включает/выключает видимость конуса.

Материал

Определяет материал конуса.

Нижний радиус

Определяет нижний радиус конуса.

Верхний радиус

Определяет верхний радиус конуса

Высота

Определяет высоту конуса по оси Z.

НачалоРазвертки

Определяет начальный угол (в градусах) охвата поверхности конуса.

КонецРазвертки

Определяет конечный угол (в градусах) охвата поверхности конуса.

Секции

Определяет количество секций, созданных между НачалоРазвертки и КонецРазвертки в конусе. Низкое значение создает пирамиду/пирамидальную усеченную вершину.

Кэпы

Включает/выключает отрисовку колпачков для конуса.

Физика

Определяет набор физических свойств объекта.
