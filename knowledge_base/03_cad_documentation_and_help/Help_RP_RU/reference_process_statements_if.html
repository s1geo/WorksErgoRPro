Если

Оператор Если (If) позволяет выполнять область операторов Then или Else в зависимости от условия. Если условие истинно, процесс выполняет операторы в Then-области. Если условие ложно, процесс выполняет операторы в Else-области.

Описание

Состояние

Определяет выражение, которое при оценке возвращает значение True или False.

 

Значение True выполняет область операторов Then.

Значение False выполняет область операторов Else.
