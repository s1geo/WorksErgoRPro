Карта логических сигналов

Логическая карта сигналов позволяет отображать сигналы на порты в непрерывном пространстве ввода-вывода.

Свойства

Название

Описание

Наименование

Определяет имя карты сигналов.

ИндексНачала

Определяет начальный индекс сигналов.

ИндексКонца

Определяет конечный индекс сигналов

Слушатели

Определяет список поведений, использующих карту сигналов. Как правило, исполнитель робота использует карты сигналов для определения IO робота.

Направление

Определяет направление сигналов (вход/выход)
