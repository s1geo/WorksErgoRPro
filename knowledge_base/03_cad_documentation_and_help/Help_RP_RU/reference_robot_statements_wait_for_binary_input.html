Ожидать бинарный вход

Оператор Ожидать бинарный вход  задерживает выполнение программы робота до тех пор, пока значение сигнала, отображаемого на входной порт в роботе, не будет иметь определенное значение. Оценка входного порта может быть циклической или запускаться сигнальным событием.

Свойства

Название

Описание

ВходнойПорт

Определяет входной порт робота, оцениваемый оператором.

ВходноеЗначение

Определяет, должно ли значение ВходнойПорт быть истинным или ложным для завершения инструкции.

ТриггерОжидания

Определяет режим оценки для ВходнойПорт.

Значение True ожидает сигнального события или триггера, тогда как значение False не будет ждать проверки значения ВходнойПорт.

Примечание: Сигнальное событие или триггер должно произойти, пока робот выполняет оператор, иначе робот пропустит событие.
