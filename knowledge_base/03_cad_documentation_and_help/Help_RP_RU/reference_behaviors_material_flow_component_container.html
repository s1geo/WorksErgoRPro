Контейнер компонентов

Контейнер компонентов позволяет вам содержать в нем компоненты. Компоненты можно перемещать в контейнер, помещать туда другие компоненты, а также добавлять с помощью скрипта Python.

 

Порты контейнера компонентов перечислены вместе с поведением на панели Диаграммы Компонента.

Свойства

Название

Описание

Наименование

Определяет наименование контейнера.

Статистика

Определяет поведение статистики, которое собирает статистику, созданную контейнером.

Вместимость

Определяет количество компонентов, которые могут находиться в контейнере в любой момент времени.

Блоки емкости

Определяет список вариантов поведения контроллера емкости для глобального определения емкости контейнера. Как правило, контроллер емкости используется в качестве переменной для управления емкостью одного или нескольких контейнеров, чтобы избежать взаимной блокировки.

СигналПерехода

Определяет логический сигнал, сигнализирующий о прибытии и уходе компонента в контейнере. Значение True сигнализирует о прибытии компонента. Значение False сигнализирует об уходе компонента.

Местоположение

Определяет объект Рамка, который действует как физическое местоположение контейнера.
