Датчик луч

Датчик луч позволяет направлять луч в трехмерный мир для измерения расстояний и обнаружения компонентов.

Свойства

Название

Описание

Наименование

Определяет наименование датчика.

ОбновитьСцену

Определяет, обновляется ли мир моделирования (все компоненты) в каждой выборке (время выборки). Для обнаружения движущихся компонентов требуется значение True. И если значение True, для повышения производительности назначьте контейнер обнаружения для обновления только содержащихся в нем компонентов, а не всего мира. В противном случае, для повышения производительности, используйте значение False.

ТестироватьГлавный

Определяет, обнаруживает ли датчик геометрию в узле, к которому он подключен. Как правило, значение True используется для обнаружения самостолкновений, например, дверей в оборудовании, сталкивающихся друг с другом.

ПоказыватьЛуч

Включает/выключает видимость луча в 3D мире.

ИспользоватьИмпульс

Определяет, работает ли датчик с использованием интервала выборки или импульса, управляемого полученным сигналом. Значение True использует режим выборки и дополнительно определяется с помощью ВремяВыборки. Значение False использует импульсный режим, в котором сигнал действует как триггер для обнаружения компонентов. В импульсном режиме свойство Connections поведения типа сигнала имеет датчик, указанный как соединение, и для работы с датчиком используется некоторая итерация, например цикл, написанный в сценарии Python, или некоторая логика, определяющая частоту сигнала.

ВремяВыборки

Определяет временной интервал между каждой выборкой, если ИспользоватьИмпульс включен. То есть интервал выборки датчика.

МаксДиапазон

Определяет диапазон, используемый датчиком для измерения расстояний. Например, если обнаруженный компонент находится ближе, чем МаксДиапазон, датчик будет сигнализировать о расстоянии компонента, используя СигналКомпонента.

ПорогОбнаружения

Определяет диапазон, используемый датчиком для обнаружения компонентов. Например, если обнаруженный компонент находится ближе, чем ПорогОбнаружения, датчик активирует СигналКомпонента и ЛогическийСигнал.

КонтейнерОбнаружения

Определяет, обнаруживает ли датчик только компоненты в указанном контейнере, например путь в компоненте датчика.

ДиапазонСигнала

Определяет вещественный сигнал, используемый для передачи сигнала о длине луча до обнаруженного компонента.

СигналКомпонента

Определяет компонентный сигнал, используемый для обозначения того, какой компонент был обнаружен датчиком.

ЛогическийСигнал

Определяет логический сигнал, используемый для подачи сигнала, когда компонент запускает датчик.

Рамка

Определяет объект Frame, указанный как физическое местоположение датчика. Луч датчика отбрасывается в положительном направлении оси Z элемента Frame.
