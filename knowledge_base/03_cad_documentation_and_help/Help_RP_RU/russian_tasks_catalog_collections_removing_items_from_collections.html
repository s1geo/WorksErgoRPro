Удаление объектов из Коллекций

Вам нужно использовать быстрый доступ для удаления элементов из коллекции.

1.Перейдите на панель Каталог.

2.Щелкните коллекцию, чтобы отобразить ее элементы.

3.В области Отображения выберите элементы, которые хотите удалить.

4.Щелкните выделенный фрагмент правой кнопкой мыши и выберите Удалить.
