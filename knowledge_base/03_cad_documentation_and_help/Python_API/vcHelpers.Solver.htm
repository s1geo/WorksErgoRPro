vcHelpers.Solver

vcHelpers.Solver provides a method and callback function for finding a local minimum, which is helpful for solving numerical problems.

Methods

Name Return Type Parameters Description
findLocalMinimum Real Function evaluator, List of Real values Calls a given function and modifies a list of values until the evaluator returns a minimum real value.

Examples

Example. Calculate local minimum

from vcScript import *
import vcHelpers.Solver
 
def calcError(pl):
  targetvalues = [1.0,-20.0,45.0]
  error = 0.0
  for i in range(3):
    error += abs(targetvalues[i]-pl[i])
  print error, pl
  return error
 
initialguess = [0.0, 0.0, 0.0]
noise = vcHelpers.Solver.findLocalMinimum(calcError,initialguess)
print noise, initialguess
