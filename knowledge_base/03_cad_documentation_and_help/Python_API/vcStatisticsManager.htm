vcStatisticsManager

vcStatisticsManager is used by a vcSimulation object for defining the sampling rate at which interval based statistics are recorded during a simulation.

Properties

Name Type Access Description
SamplingInterval Real RW Defines the sampling interval used by simulation for recording interval based statistics.

The default rate is 60.0 seconds, so an interval is recorded every 60 seconds in simulation.

Examples

Example. Define global interval for interval based statistics in a simulation

from vcScript import *
 
sim = getSimulation()
stats = sim.Statistics
 
#Define global interval statistics sampling interval
stats.SamplingInterval = 10.0
