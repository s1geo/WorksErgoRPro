vcTransportController

vcTransportController is a base class for transport controllers, which implement transport of product instances over transport links. The system conveyor transport controller uses the generic vcTransportController.

Note: When implementing your own transport controller, use vcPythonTransportController.

Inherits: vcBehaviour

Type constants: VC_TRANSPORTCONTROLLER, VC_CONVEYORTRANSPORTCONTROLLER
