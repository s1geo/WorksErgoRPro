vcSelection

vcSelection allows you to access and manipulate selections in the application.

Properties

Name Type Access Description
Count Integer R Gets the number of items in selection.
IgnoreEvents Boolean RW Defines if selection ignores event passing in order to avoid cyclic calls.
Name String R Gets the name of selection.
Objects List of <Type> R Gets a list of all objects in selection.
Type Enumeration R Gets the selection type.

See Selection Constants for more information.

Methods

Name Return Type Parameters Description
addItem None <Type> item

or

vcNode node, <Type> item

 Adds a given item or an item in a given node to selection if item is a supported selection type.

See Selection Constants for more information.
beginUpdate None None Blocks the application from doing update procedures while an item is being added to selection, thereby improving system performance.

This method should be called before selecting any items.
clear None None Removes all items from selection.
endUpdate None None Unblocks the application and sends a notification to update selection in scene.

This method should be called after the last item is added to selection.
getCommand vcCommand String name Returns a registered command matching a given name.

The command should support the selection of an item, for example, Select, Translate, Rotate, Delete, Cut, Copy, and Paste.
getItem <Type> Integer index Returns an item at a given index in selection.
getItemNode vcNode Integer index Returns the node containing an item at a given index in selection.
getItemWorldMatrix vcMatrix Integer index Returns the position matrix of an item at a given index in selection.
registerCommand None String name, vcCommand command, [Enumeration options] Registers a given command with selection and creates a command shortcut/menu item.

The name argument defines the name of command displayed in shortcut menu.

An optional options argument can be given to enable command based on selection : when no objects are selected; a single object is selected; or multiple objects are selected.

See Selection Constants of command type for more information or Examples section of this topic.
removeItem None <Type> item

or

vcNode node, <Type> item

 Removes a given item or an item in a given node from selection.
