vcProcessFlowTable2

FlowTable2 contains a list of ProcessSequence2, one or none for each ProcessFlowGroup.

Properties

Name Data type Access Description
Controller vcProcessController R Owner of this FlowTable2
Sequences vcProcessSequence2[] R List of sequences

Methods

Name Return Type Parameters Description
createSequence vcProcessSequence2 or None vcProcessFlowGroup group Creates sequence associated with given FlowGroup. Returns None, if sequence already exists.
deleteSequence None vcProcessFlowGroup group Deletes sequences associated with given FlowGroup.
getSequence vcProcessSequence2 or None vcProcessFlowGroup group Gets sequence associated with given FlowGroup. Returns None, if FlowGroups does not have a sequence.
copySequenceFrom vcProcessSequence2 or None vcProcessFlowGroup source, vcProcessFlowGroup target Copies a sequences from FlowGroup `source` to FlowGroup `target`. Returns None (and does nothing), if the target FlowGroup already has a sequence.

Events

Name Parameters Description
OnSequenceAdded vcProcessSequence2 Triggered when a sequence is added.
OnSequenceRemoving vcProcessSequence2 Triggered when a sequence is being removed.
