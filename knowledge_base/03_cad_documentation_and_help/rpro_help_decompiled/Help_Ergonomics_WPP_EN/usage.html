Usage

Description of the addon

Launch the Rational Production software.

- To start working, load the required layout.

- The layout must contain the component «MoCap Operator (Name) WPP», which can be found in the electronic catalog «PM MoCap» (Fig. 1).

Figure 1 – MoCap operator in the electronic catalog

- In the «Program» tab, find the «Ergonomics» section, select the «Ergonomics WPP» tool (Fig. 2-3).

Figure 2 – New section «Ergonomics WPP» in the «Programming» tab

Figure 3 – Addon appearance

- Next, you need to select the operator. You can select it using the drop-down list or from the layout (Fig. 3).

- To manipulate any link of the operator, you need to select the link. You can select it using the drop-down list or from the layout (Fig. 3). You can also control the list using the key combinations Ctrl + J (back) and Ctrl + K (forward).

- The button "Offset origin point to selected link" helps to move the starting point of the component to the selected link (Fig. 3).

- It is possible to change the display of the operator on the layout, go to the «Display» tab and select the desired settings (Fig. 4-10).

- The «View window» tab is designed to view the operator's first-person view in a separate window (Fig. 11). Click the "Open view window" button to see POV of the operator.

Figure 11 – «View window» tab

- The «Limits» tab is responsible for setting up different viewing angles, the «Distance» tab is responsible for setting up the viewing range and focus point (Fig. 11).

- It is also possible to select different view types (Fig. 12-16).

- The «Operator posture editor» tab helps us turn on/off the manipulator. The key combination also turns on/off the manipulator Ctrl+M (Fig. 17). The selected node will be displayed below the «Initial posture» tab and will show the current rotation angles of the body part.

Figure 17 – «Operator posture editor» tab

- The drop-down list «Initial posture» allows you to set the operator's initial pose. There is a refresh button (Fig. 18-23).

- The manipulator allows working with various parts of the operator's body, all movement options are highlighted simultaneously, limiting angles, and parts of the manipulator are highlighted based on the results of the ergonomics assessment (Fig. 24-25).

 

Figure 24 – Interaction with the manipulator

Figure 25 – Manipulator without interaction

- To avoid incorrect operation with the operator, it is recommended to avoid changing the rotation angles in the «Jog» tab.

- When working with the Pelvis_R link, the hip angle changes opposite to the pelvic rotation to maintain the vertical position of the operator model.

- The «Apply color to operator body parts» checkbox is responsible for displaying the ergonomics assessment in color directly on the operator (Fig. 26).

 Рисунок 26 – Apply color to operator body parts

- The «Standard posture» tab helps us put the operator in a certain pose, which can be edited more conveniently (Fig. 27-34). The «Maintain gaze direction» button allows you to keep the head in a certain direction unchanged up to maximum angles.

- The "Posture" tab allows you to evaluate the current static pose of the operator. The result is presented in the form of a table (Fig. 35) (Table 1-2). Here you can select whether the operator has a comfortable support, the duration of being in this pose in seconds, weight/effort in kilograms.

- The «Get posture assessment report» button writes all input data and ergonomics assessment results in .pdf format (Fig. 36).
