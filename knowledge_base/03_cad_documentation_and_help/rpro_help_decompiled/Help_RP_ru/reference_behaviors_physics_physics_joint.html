Физическое соединение

Физическое соединение позволяет настроить соединение D6 с несколькими степенями свободы для компонента в трехмерном мире.

Свойства

Название

Описание

Наименование

Определяет наименование соединения.

Прикреплен к

Определяет узел, к которому присоединяется соединение в компоненте.

В некоторых случаях это может быть родителем узла, содержащего соединение. Например, Физическое соединение в узле второй оси для робота может быть присоединен к узлу первой оси.

В других случаях ваша настройка соединения будет определять, к какому узлу он должен прикрепляться в компоненте.

Ограничения

Набор свойств для настройки сустава. То есть ограничения для перемещений и поворотов в осях системы координат.

Каждому свойству может быть назначено собственное ограничение.

#Free - Не сковывает движения.

#Limited - Ограничивает движение.

#Locked - Заблокировано любое движение.

Разрыв

Набор свойств для определения целостности соединения.

Настройки Привода

Набор расширенных свойств для настройки физики сустава и его степеней свободы.
