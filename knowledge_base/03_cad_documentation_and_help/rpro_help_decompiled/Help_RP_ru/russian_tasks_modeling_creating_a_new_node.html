Создание нового узла 

Звено — это узел, добавленный в структуру компонента, который в основном используется для определения соединений и других механизмов движения в компоненте.

1.Либо создайте, либо выберите компонент в 3D-мире.

2.Нажмите на вкладку Моделирование, а затем в панели Диаграмма компонента в Дереве узлов компонента, выберите узел. Это определяет родителя нового узла, который вы собираетесь создать в компоненте.

3.На вкладке Моделирование, в группе Структура, нажмите Создать звено.
