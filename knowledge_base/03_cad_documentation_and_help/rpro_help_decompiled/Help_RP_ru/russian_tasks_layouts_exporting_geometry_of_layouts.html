Экспорт геометрии планировки 

Геометрию всей планировки можно экспортировать как файл поддерживаемого типа.

1.На вкладке Главная, в группе Экспорт, нажмите Геометрия.

2.На панель задач Экспорт планировки, в поле Компонент нажмите Все.

3.В списке Формат файла, выберите поддерживаемый формат файла по вашему выбору.

4.Нажмите Экспорт, а затем сохраните файл.
