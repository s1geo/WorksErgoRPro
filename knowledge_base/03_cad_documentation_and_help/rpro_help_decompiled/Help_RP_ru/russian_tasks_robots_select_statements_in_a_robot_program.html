Выбор операторов в программе робота 

Панель редактора программ используется для просмотра программы робота, а также для создания и редактирования операторов в подпрограммах.

1.Нажмите на вкладку Программирование, а затем с помощью команды Взаимодействие выберите робота, которого вы хотите запрограммировать в 3D-мире.

2.В Редакторе программы на панели Подпрограммы нажмите на подпрограмму, чтобы получить список ее операторов.

3.В подпрограмме, сделайте одно из следующих действий:

·Чтобы напрямую выбрать оператор, щелкните его.

·Чтобы выбрать вложенный оператор, разверните родительский элемент оператора, а затем щелкните вложенный оператор.

Подсказка: Позиции в программе робота можно выбирать так же, как и любой другой компонент в 3D мире. Вы можете использовать команду Переместить или Выделить, чтобы предотвратить перемещение робота в выбранное положение.
