Сигналы

Тип поведения сигнал используется для отправки и получения различных типов данных.

Типы

Название

Описание

Булевый

Отправляет/получает значение True или False.

Булевая карта

Обеспечивает непрерывное пространство ввода-вывода для отображения сигналов на порты.

Компонентный

Отправляет/получает компонент как значение.

Целочисленный

Отправляет/получает целое число.

Матричный

Отправляет/получает матрицу 4x4 в качестве значения.

Вещественный

Отправляет/получает вещественное число.

Строковый

Отправляет/принимает строку символов.
