Исполнитель

Исполнитель позволяет вам читать, писать и выполнять программу робота.

Свойства

Название

Описание

Наименование

Определяет наименование исполнителя.

ЦифровыеВходныеСигналы

Определяет поведение Карта логических сигналов, используемое для управления входными данными исполнителя.

ЦифровыеВыходныеСигналы

Определяет поведение Карта логических сигналов, используемое для управления выходными данными исполнителя.

Зацикливание

Определяет, зацикливает ли исполнитель свою программу.

ОбработчикОператоров

Определяет обработчики процессов Python, используемые для переопределения или изменения операторовв программе робота и выполнения операторов процесса.

Включен

Включает/выключает выполнение своей программы.

Контроллер

Определяет контроллер робота/сервопривода, используемый исполнителем для генерации операторов движения в своей программе.

Если сервоконтроллер, вы можете генерировать движения шарнирного типа, но не линейные движения. Если это контроллер робота, вы можете генерировать как шарнирные, так и линейные движения.
