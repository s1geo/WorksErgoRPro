Статистика

Поведение Статистика позволяет собирать и сообщать статистику, сгенерированную другими поведениями в компоненте во время моделирования.

Свойства

Сбор данных может быть кумулятивным или основываться на времени, состояниях и событиях. Чтобы сообщать статистику, поведение должно иметь свойство Statistics, иначе вы можете использовать скрипт Python для ручного определения сбора данных. По умолчанию статистика на основе интервалов сообщается каждые 60 секунд в работающем моделировании.

Состояния

Компонент может иметь одно или несколько состояний, которые определяются поведением статистики. Состояние — это состояние компонента во время симуляции в данный момент времени. Вот почему каждое состояние имеет два динамических свойства: State<StateName>Percentage и State<StateName>IntervalPercentage. Состояние сопоставляется с состоянием системы, которое является жестко запрограммированным, предопределенным условием для компонента.

 

Создание состояний по умолчанию.

Свойство поведения Статистика позволяет создавать следующие восемь состояний.

Название

Описание

Blocked

Указывает, что компонент заблокирован, например, проблема с емкостью или части застряли в процессе.

Break

Указывает на сбой в компоненте, например, на сбой в процессе.

Broken

Указывает на сбой в компоненте, например, что-то сломано и нуждается в ремонте.

Busy

Указывает, что компонент занят, например, выполнением процесса.

Idle

Указывает, что компонент не занят, например, не ожидает команды или не выполняет процесс.

Repair

Указывает на ремонт компонента, например, на ремонт сломанной детали.

Setup

Указывает, что компонент настраивается, например, процесс загрузки или шаги перед выполнением процесса.

Warmup

Указывает время подготовки компонента (прогрев).

Примечание:

·Вы можете переименовать состояние, но оно всегда должно быть сопоставлено с состоянием системы.
