Сервоконтроллер

Сервоконтроллер позволяет настраивать и контролировать независимые соединения и механизмы с помощью прямой кинематики.

Свойства

Название

Описание

Наименование

Определяет наименование контроллера.

Соединения

Определяет список соединений, определенных в узлах, используемых контроллером.

ИспользоватьТакт

Включает/выключает использование такта для управления событиями.

ВремяТакта

Определяет время между каждым тактом (в секундах), если ИспользоватьТакт включен.

КорневойУзел

Определяет звено/узел, который выступает в качестве основы механической структуры.

ФланцевыйУзел

Если вы используете внешнюю систему координат, определяет звено/узел, используемый в качестве монтажной пластины для других кинематических структур. Если вы используете дорожку, определяет звено/узел, используемый в качестве каретки.

КорневоеСмещение

Определяет смещение от начала корневого узла в кинематике. Как правило, это используется для запуска кинематики от центра узла, а не от его стороны.

СмещениеФланца

Определяет смещение от начала координат ФланцевыйУзел для правильного монтажа других кинематических структур.
