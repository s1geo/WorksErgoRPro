Выдавливание

Элемент Выдавить выдавливает геометрию своих дочерних элементов.

Выдавливание можно использовать для деформации и искажения объектов, а также для выдавливания поверхностей.

Свойства

Название

Описание

Наименование

Определяет наименование элемента.

Материал

Определяет материал экструзии.

Кэпы

Включает/выключает отрисовку кэпов при выдавливании.

Реверсирование

Включает/выключает изменение направления экструзии.

ПоказатьЗадниеГрани

Включает/выключает рендеринг обратных сторон в экструзии.

Направление

Определяет направление выдавливания.

Длина

Определяет длину экструзии.

Физика

Определяет набор физических свойств объекта.
