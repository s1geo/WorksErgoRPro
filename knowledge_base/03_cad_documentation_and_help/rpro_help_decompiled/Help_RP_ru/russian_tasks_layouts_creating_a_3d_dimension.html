Создание 3D-размера 

Размер позволяет визуализировать расстояния и углы между линиями, точками и ребрами в мире моделирования.

1.На вкладке Главная, в группе Размеры, выберите одно из следующих действий:

·Линейный, чтобы измерить расстояние.

·Угловое, чтобы измерить угол.

2.В мире симуляции выберите две точки, определяющие размер, а затем определите положение точки для расположения измеренного значения. Если вам нужно выбрать разные типы точек, используйте панель задач Линейный размер для настройки активного параметра Тип привязки (для команды Угловой размер привязки отсутствуют).
