Присвоить переменную

Оператор Присвоить переменную позволяет установить значение переменной процесса.

Примечание: Инструкция Assign не поддерживает переменные продукта в экземплярах Product. Однако вы все равно можете присвоить переменной Product пустое значение (null), чтобы повторно использовать ее, например, в цикле while.
