Кинематика 

Тип поведения кинематика используется для определения прямой и/или обратной кинематики компонента и его узловой структуры, например роботов.

Типы

Название

Описание

Шарнирная кинематика

Определяет кинематику шарнирных роботов, например, шестиосевых роботов.

Декартова кинематика

Определяет кинематику линейных роботов, например трехосных роботов, с дополнительной поддержкой движения запястья по трем осям.

Дельта-кинематика

Определяет кинематику роботов дельта-типа.

Кинематика параллелограмм

Определяет кинематику роботов параллелограммного типа.

Кинематика Python

Определяет пользовательскую кинематику для компонентов с помощью скриптов.

Скара Кинематика

Определяет кинематику роботов типа SCARA.

Назначение

Во всех случаях поведение кинематического типа должно быть назначено для поведения Контроллера робота для использования при решении кинематических уравнений.

Использование поведения кинематического типа не избавляет от необходимости правильно определять соединения компонента.
