Модель процесса

Тип поведения модель процесса предназначено для определения продуктов, процессов и потоков.

Типы

Название

Описание

Исполнитель процесса

Предоставляет логический контейнер и исполнитель для подпрограмм процесса.

Генератор продуктов

Создает продукты динамически во время симуляции.

Транспортный контроллер

Определяет контроллер ресурсов для транспортировки.

Транспортный узел

Промежуточный пункт для потока, куда можно ввозить/вывозить продукты.
