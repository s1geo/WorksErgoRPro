Кинематика Scara (устаревшее)

Поведение кинематика Scara вычисляет прямую и обратную кинематику контроллера робота для робота типа SCARA, в котором запястье определяется по одной оси (обычно по оси Z) и имеет две возможные конфигурации (левая и правая).

Примечание : Это устаревшая версия, используйте Кинематика Scara для новых моделей.
