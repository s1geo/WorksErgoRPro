Правило маршрутизации

Правило маршрутизации позволяет направлять компоненты в разные контейнеры и из них на основе одного или нескольких уровней условных операторов.

Порты правила маршрутизации перечислены вместе с поведением на панели Диаграммы компонента.

Свойства

Название

Описание

Наименование

Определяет наименование маршрутизатора.

Статистика

Определяет поведение статистики, которое собирает статистику, сгенерированную маршрутизатором.

Вместимость

Определяет количество компонентов, которыми маршрутизатор может управлять в любой момент времени.

БлокиВместимости

Определяет список режимов работы контроллера емкости для глобального определения емкости маршрутизатора. Как правило, контроллер емкости используется в качестве переменной для управления емкостью одного или нескольких контейнеров, чтобы избежать тупиковых ситуаций.

СигналПерехода

Определяет логический сигнал, сигнализирующий о прибытии и уходе компонента в маршрутизаторе. Значение True сигнализирует о прибытии компонента. Значение False сигнализирует об уходе компонента.

ПравилоКомпонента

Определяет, выполняется ли обработка правил для компонента маршрутизатора или компонента, содержащегося в маршрутизаторе.

СохранитьСмещение

Включает/выключает возможность сохранять положение компонента при его прохождении по маршруту.

Разъемы

Правило маршрутизации использует соединители/коннекторы для подключения к другим поведениям и передачи входящих и исходящих компонентов.

Название

Описание

Добавить коннектор

Добавляет новый порт в маршрутизатор.

Ярлык: На панели Диаграмма компонента щелкните правой кнопкой мыши поведение правила маршрутизации и выберите Добавить коннектор

Маршрут

Маршрут определяется с помощью одного или нескольких правил, образующих вложенную структуру. В некоторых случаях правила могут напрямую маршрутизироваться к соединению/порту. В других случаях правило может использовать другое правило для определения маршрута компонента. Во всех случаях изменение правила отменяет все его дочерние правила. В крайнем случае, некоторые правила позволяют определить соединение или правило по умолчанию.

Подсказка: Правила маршрутизации можно изменить на панели свойств компонента.

Название

Описание

Правило Логической таблицы

Направляет компоненты к выбранному порту на основе значения True или False.

Переменная - Определяет, какое свойство обрабатываемого компонента или компонента-владельца оценивается правилом.

По умолчанию - Используется, если значение Переменная не соответствует ни одному из перечисленных значений в таблице.

Правило Емкости

Направляет компоненты на первый выбранный порт, прошедший проверку пропускной способности.

Циклическое правило

Направляет компоненты к выбранным портам последовательно перед повторением того же цикла.

CycleOnlyConnected - Может использоваться только для маршрутизации к портам, которые подключены к другим портам.

Фиксированное правило

Направляет компоненты из выбранного порта в другой выбранный порт.

CycleOnlyConnected - Может использоваться только для маршрутизации к портам, которые подключены к другим портам.

Правило Целочисленной таблицы

Направляет компоненты к выбранному порту на основе целочисленного значения.

Переменная - Определяет, какое свойство в обрабатываемом компоненте или компоненте-владельце оценивается правилом.

По умолчанию - Используется, если значение Переменная не соответствует ни одному из перечисленных значений в таблице.

Правило Процента

Направляет компоненты к выбранным портам на основе процентного распределения.

RandomStream - Может использоваться для заполнения значения.

Во всех случаях общий процент для всех выбранных портов должен составлять 100.

<Порт>

Направляет компоненты на выбранный порт.

Например, все входящие компоненты маршрутизатора будут выходить из выбранного порта. Как правило, доступно только как правило уровня 1.

Правило типа продукта

Направляет компоненты к выбранному порту на основе выбранного типа продукта или группы потоков.

По умолчанию - Используется, если значение Переменная не соответствует ни одному из перечисленных значений в таблице.

По умолчанию - Используется, если значение Переменная не соответствует ни одному из перечисленных значений в таблице.

Правило строковой таблицы

Направляет компоненты к выбранному порту на основе строкового значения.

Правило транспортного решения

Направляет продукты в выбранный порт на основе транспортного решения.

ПеременнаяПравила - Определяет, какой транспортный узел обработанного продукта оценивается правилом..

Примечание: Обработка правил выполняется только для продуктов, содержащихся в маршрутизаторе.

Правило типа продукта

Направляет продукты на выбранный порт в зависимости от типа продукта.
