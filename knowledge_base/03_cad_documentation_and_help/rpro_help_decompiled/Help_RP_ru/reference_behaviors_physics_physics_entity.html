Физический объект

Физический объект позволяет определить узел в компоненте как физическое тело, на которое влияет физика трехмерного мира.

Свойства

Название

Описание

Наименование

Определяет наименование объекта.

Физический Тип

Определяет, как физика влияет на объект во время симуляции.

#В физике -На объект действует гравитация и другие силы.

#Вне физики - Объект не зависит от физики.

#Кинематический - На объект не влияет гравитация, но она может управляться другими силами, например траекториями и сервоприводами.

#В контейнере - Аналогичен #В физике, но используется для отслеживания содержания объекта, например, от одного пути к другому.

Плотность Материала

Определяет плотность объекта, тем самым влияя на его массу.

Плотность измеряется в кг/м^3. Системное значение по умолчанию — 0,2 и используется, если значение равно 0.

Статическое Трение

Определяет статическое трение объекта как коэффициент для расчета его силы трения.

Значение находится в диапазоне от 0 до 1 со значением по умолчанию 0,5. Это используется, когда объект, которого он касается, не двигаются относительно друг друга.

Динамическое Трение

Определяет динамическое (кинетическое) трение объекта как коэффициент для расчета его силы трения.

Значение находится в диапазоне от 0 до 1 со значением по умолчанию 0,5. Это используется, когда объект, которого он касается, движутся относительно друг друга.

Реституция

Определяет прыгучесть объекта как фактор его скорости до и после столкновения с другим объектом.

Значение находится в диапазоне от 0 до 1 со значением по умолчанию 0,1. Значение 1 очень упругое (упругое столкновение). Значение меньше 1 означает меньшую упругость (неупругое столкновение).

Линейное Затухание

Определяет линейное демпфирование объекта как коэффициент для расчета его сопротивления линейному движению.

Значение находится в диапазоне от 0 до 1, по умолчанию 0.

Угловое Затухание

Определяет угловое демпфирование объекта как коэффициент для расчета его сопротивления вращательному движению.

Итерации Позиции Программы Решателя

Определяет количество итераций, используемых для определения положения объекта.

Системное значение по умолчанию равно 4 и используется, если значение равно 0.

Итерации Скорости Программы Решателя

Определяет количество итераций, используемых для определения скорости объекта.

Системное значение по умолчанию равно 1 и используется, если значение равно 0.

Id Cцены

Определяет идентификатор сцены, которой принадлежит объект в 3D-мире.

По умолчанию все объекты и пол 3D-мира имеют идентификатор сцены 0. Сцена в этом контексте является абстрактной и более или менее многослойной. Сущности в разных сценах не будут сталкиваться друг с другом.

Группа Cтолкновения

Ограничивает столкновение сущности с другими объектами теми, которые принадлежат к той же группе.

Шагов Сглаживания

Определяет количество шагов для сглаживания анимации объекта, например, при его движении.
