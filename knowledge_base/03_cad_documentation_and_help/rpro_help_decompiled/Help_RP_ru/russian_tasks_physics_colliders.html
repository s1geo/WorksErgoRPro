Столкновения в мире физики 

ГеометрияСтолкновения - это объект, который может реагировать на физические объекты во время симуляции. Каждая ГеометрияСтолкновения представляет собой оболочку, охватывающую геометрию элемента в компоненте. Каждый элемент, включая корневой элемент узла, имеет собственное свойство ГеометрияСтолкновения.

Название

Описание

Undefined

ГеометрияСтолкновения не определена для элемента.

#None

ГеометрияСтолкновения отключена и не создана для элемента.

#Box

ГеометрияСтолкновения активна, и её форма — ограничивающий параллелепипед элемента.

#Boxes

ГеометрияСтолкновения активена, и её форма представляет собой набор ограничивающих параллелепипедов для каждого набора геометрии в элементе и дереве его подэлементов.

Как правило, этот режим доступен только в корневом элементе узла.

#Precise

ГеометрияСтолкновения активена, и её форма представляет собой треугольную сетку, охватывающую элемент.

 

Корневой элемент узла может использоваться для переопределения или принудительного наследования Геометрии Столкновения во всех элементах этого узла. В любом случае узел должен быть физическим объектом, чтобы ГеометрияСтолкновения работала во время симуляции. То есть узел должен иметь по крайней мере одно поведение физического объекта, которое определяет физические свойства узла.

Примечание: Если у узла нет поведения физического объекта, а для ГеометрииСтолкновения установлен режим, отличный от Undefined или #None, поведение физического объекта будет автоматически создано в этом узле.
