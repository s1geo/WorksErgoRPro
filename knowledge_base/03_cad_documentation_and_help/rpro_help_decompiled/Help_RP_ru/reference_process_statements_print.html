Печать

Оператор Печать позволяет печатать пользовательские сообщения на панели вывода.

Свойства

Название

Описание

Сообщение

Сообщение, которое будет напечатано на панели вывода

Предзаголовок

При значении True сообщение печатается вместе с префиксом, указывающим на его владельца.

ComponentName::ProcessExecutorName::ProcessRoutineName:YourMessage

В противном случае печатает только ваше сообщение.
