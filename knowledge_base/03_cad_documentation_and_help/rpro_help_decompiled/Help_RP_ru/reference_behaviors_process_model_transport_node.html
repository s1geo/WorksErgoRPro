Транспортный узел

Транспортный узел — это место, куда продукты могут направляться и выходить с помощью Flow Editor.

Имя поведения транспортного узла

УправляющаяПрограммаПроцесса

Поведение управляющей программы процесса для уведомления о прибытии и уходе деталей. Это также можно обновить, назначив свойство Транспортный узел в Исполнителе Процесса.

КонтейнерКомпонентов

Транспортный узел реагирует на продукты, прибывающие и покидающие этот контейнер.

Примечание: вы должны связать поведение контейнера с отдельным компонентом, даже если транспортный узел используется в режиме точки движения (как процесс присоединенный к пути).

ВизуальнаяРамкаПоложения

Элемент системы координат, определяющий визуальное положение узла.

РамкаПозицииПродуктаПоумолчанию

Элемент системы координат, определяющая положение по умолчанию, используемое для продуктов, поступающих на транспортный узел.

РамкаПозицииРесурсаПоумолчанию

Элемент системы координат, которая определяет положение ресурса по умолчанию, используемое при транспортировке продуктов внутрь и наружу.
