Контроллер робота

Контроллер робота позволяет настраивать механизмы робота и управлять ими.

Системы координат баз и инструментов контроллера робота перечислены вместе с поведением на панели Диаграммы компонентов.

РежимОриентацииИнтерполяции

Определяет режим расчета ориентации робота во время линейных перемещений, в котором значения вращения робота основаны на одной, двух или трех осях.

Одна ось использует ось с наименьшим углом поворота для текущей центральной точки инструмента.

Две оси использует одну из осей XYZ и ее направление в текущей центральной точке инструмента. В этом режиме сначала применяется угол поворота для выбранной оси, а затем другие повороты основаны на этой оси.

Три оси интерполирует рыскание, тангаж и крен (WPR) или углы Эйлера (ZYZ) положения, а затем вычисляет последовательность вращений для робота.

РежимКонфигурации

Определяет режим определения конфигурации робота при интерполяции линейного движения.

Фиксированный - использует текущую конфигурацию робота для достижения позиции.

Фрейм следования - пытается сохранить текущую конфигурацию робота, поэтому для достижения позиции могут произойти небольшие изменения.

Интерполировать значения соединений - означает, что робот использует конфигурацию, основанную на двухточечной интерполяции своих суставов, чтобы достичь положения.

РежимОтслеживанияСистемыКоординатМира

Определяет рамку мира робота, когда робот установлен на гусенице.

Исходная точка Трека - помещает кадр мира в начало дорожки.

Система координат Мира Робота - сохраняет позицию Мирового фрейма в роботе.
