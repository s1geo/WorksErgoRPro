Параллелепипед

Элемент параллелепипед представляет собой форму куба/коробки.

Как правило, параллелепипед формируется и делается параметрическим с использованием выражений со свойствами компонентов.

Свойства

Название

Описание

Определяет наименование параллелепипеда.

Видимый

Включает/выключает видимость параллелепипеда.

Материал

Определяет материал параллелепипеда.

Длина

Определяет длину параллелепипеда по оси X.

Ширина

Определяет ширину/глубину параллелепипеда по его оси Y.

Высота

Определяет высоту параллелепипеда по оси Z.

Физика

Определяет набор физических свойств объекта.
