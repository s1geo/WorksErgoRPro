Если

Оператор Если (If) выполняет область Then, Else, или Else If на основе условия.

Оператор инициализирует области с Then и Else.Один или несколько диапазонов Else If можно добавить, щелкнув значок «+», который отображается при наведении указателя мыши на оператор If. Каждая область Else If имеет свое собственное условие.

Область Then выполняется, если условие оператора If истинно.

Область Else If выполняется, если условие Then ложно, а у него истинное условие.

Область Else выполняется, если другие условия ложны.

Состояние

Определяет выражение, которое при оценке возвращает значение True или False.

Значение True выполняет область операторов Then.

Значение False выполняет область операторов Else.

Выражение может ссылаться на стандартные переменные, порты ввода-вывода робота и свойства компонентов.

Чтобы сослаться на переменную подпрограммы, оператор и переменная должны принадлежать одной и той же подпрограмме.

Чтобы сослаться на порт в роботе, используйте формат IN[<номер порта>] .

Чтобы сослаться на свойство компонента, на свойства по умолчанию можно ссылаться по имени, тогда как сгруппированное свойство должно использовать формат <имя группы/вкладки>::<имя свойства> . В этом случае вы ссылаетесь на значение свойства.
