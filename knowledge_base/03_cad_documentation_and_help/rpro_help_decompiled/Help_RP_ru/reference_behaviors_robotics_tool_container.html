Контейнер для инструментов

Контейнер для инструментов — это контейнер элементов рамок, используемых в качестве систем координат инструментов.

Рамки в контейнере инструментов перечислены вместе с поведением на панели «Диаграмма Компонента» и управляются с помощью элемента «Инструменты».

Рамка инструмента

Элемент Frame, используемый в качестве рамки инструмента или центральной точки инструмента (TCP), имеет собственный набор свойств, связанных с робототехникой.

Трансформировать

Определяет выражение для преобразования рамки инструмента, например, его положение.

Узел

Определяет узел, к которому прикрепляется инструментальная рамка в 3D-мире. В некоторых случаях это может быть монтажная пластина робота, узел в другом компоненте, используемом в качестве внешнего инструмента, или значение NULL, означающее, что фрейм относится к узлу своего контейнера.

РежимИнтерполяции

Определяет, как рама инструмента используется при интерполяции позиций робота. Как правило, инструментальная рама используется в качестве центральной точки инструмента или TCP робота. Однако рама инструмента может действовать как базовая рама или система координат робота. Одним из примеров является стационарная TCP, в которой робот перемещается в трехмерном мире.
