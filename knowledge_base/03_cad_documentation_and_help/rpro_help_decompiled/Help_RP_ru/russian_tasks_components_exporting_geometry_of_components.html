Экспорт геометрии компонентов

Геометрия одного или нескольких выбранных компонентов может быть экспортирована в новый, поддерживаемый тип файла.

1.В 3D-мире выберите компоненты, которые вы хотите экспортировать.

2.На вкладке Главная в группе Экспорт нажмите Геометрия.

3.На панели задач Экспорт планировки в разделе Компонент для экспорта нажмите Выбрано.

4.В списке Формат файла выберите поддерживаемый формат файла по своему выбору.

5.Нажмите Экспорт, а затем сохраните файл.
