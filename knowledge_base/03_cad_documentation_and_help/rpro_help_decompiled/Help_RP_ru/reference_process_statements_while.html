Пока

Оператор Пока (While) позволяет вам выполнять область операторов в цикле, пока условие истинно.

Свойства

Название

Описание

Условие

Определяет выражение, которое при оценке должно возвращать значение True или False.

 

Значение True выполняет область операторов, а затем программа возвращается назад и переоценивает Условие перед выполнением следующей итерации.

 

Значение False не выполняет область операторов и завершает оператор.

Смотрите также Выражения оператора процесса .
