Текст

Текстовый элемент— это контейнер текста, который визуализируется в трехмерном мире.

Текстовые элементы полезны для маркировки процессов и этапов на планировке, а также потока компонентов.

Свойства

Название

Описание

Наименование

Определяет наименование элемента.

Видимый

Включает/выключает видимость текста.

Материал

Определяет материал элемента.

Текст

Определяет выражение, которое при вычислении возвращает текст для визуализации в трехмерном мире.

Размер

Определяет масштабный коэффициент для изменения размера отображаемого текста.

Плавающий

Определяет, плавает ли текст свободно в трехмерном мире или привязан непосредственно к местоположению объекта.

ТолькоДляЧтения

Определяет, доступен ли текст только для чтения и заблокирован от редактирования.

Физика

Определяет набор физических свойств объекта.
