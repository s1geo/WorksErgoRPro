Редактирование операторов в программе робота

Операторы в программе робота можно редактировать с помощью панели Свойства.

1.Нажмите на вкладку Программирование, а затем используйте Взаимодействие выберите робота, которого вы хотите запрограммировать в трехмерном мире.

2.На панели Редактор программы, панель Подпрограммы, выберите подпрограмму, чтобы просмотреть ее операторы.

3.В подпрограмме выберите оператор, который вы хотите отредактировать.

4.Выполните одно или несколько из следующих действий.

·Чтобы отредактировать свойства выбранного оператора, на панели Свойства, отредактируйте одно или несколько свойств.

·Чтобы скопировать и вставить выбранный оператор, на вкладке Программирование, в группе Быстрый доступ, нажмите Копировать, а затем щелкните Вставить.

·Чтобы удалить выбранный оператор, нажмите Удалить.
