Description

 

The R-Pro MoCap add-on is designed to integrate the Perception Neuron suit with the Rational Production software environment.

This version of the add-on allows you to read and play animations in .csv format on special models, made using the Perception Neuron suit and Axis Studio software. It is assumed that the latter is supplied with the suit itself.

In addition to directly playing animations on special models, functionality has been implemented that allows you to collect statistical data from the model:

- Distance traveled.

- Ratio of time the model spent on work to the time of inactivity.

Thus, the add-on user gets the opportunity to take data from a real person and analyze them using statistics.

 

Motion capture is a method of animating characters and objects by digitizing the movements of a real object (primarily a person) and then transferring them to a three-dimensional model. The method is used in the production of computer animation, as well as to create visual effects in films and AAA games.
