vcHelpers.Application

vcHelpers.Application is a library of useful classes and methods designed to simplify common application related tasks. For example, the library contains methods for creating modal and non-modal dialog boxes as well as other methods involving user interaction and feedback.

Non-modal Dialog Box

Non-modal dialog box is a dialog that allows a user to interact with the 3D world while the dialog is open in the current session. Properties can be added to show or enter information.

See Example. Create a non-modal dialog box with tabs for a basic implementation of this dialog type.

Methods

Name Return Type Parameters Description
addProperty None String name, Enumeration type, String onchanged, Enumeration constraints Adds a new property to the dialog.

If a property with the given name exists, that property is deleted and replaced with the new property.

The onchanged argument can be used to call a function for handling property value changes; otherwise give a None value.

A tab is added to the dialog when you add a property using the following format for its name argument.

[TabName]::[PropertyName]

See Property Constants for more information on property types and constraints.
destroyWindow None None Hides and destroys the dialog.
getProperty vcProperty String name Returns a property of the dialog matching the given name; otherwise returns None.
hide None None Hides the dialog.
show None None Shows the dialog.
showTabs None [String tabName] Shows the dialog and its tabs.

An optional tabName argument can be used to define which tab is listed first and active in the dialog.

If there is no tab matching the given tabName or the method is called without any argument, the first listed tab is used in the dialog. By default, the first tab is named General.

Modal Dialog Box

The modal dialog box is a dialog used to request essential information for a user. When this type of dialog is shown, interaction with the 3D world cannot proceed until a user closes the dialog.

See Example. Command to create a modal dialog box with tabs for a basic implementation of this dialog type.

Constructors

None. This type of dialog box is created by using the displayPropertyDialog() method to call a modal dialog box bound to a vcCommand type object which acts as the owner of the dialog and its properties.

displayPropertyDialog Boolean String cmdName, String title, String firstTabName Shows a modal property dialog bound to a command matching the given cmdName.

The cmdName argument is used to find a command owning the dialog and its properties.

The title argument defines the caption of the dialog's title bar.

The firstTabName argument defines the first and active tab of the dialog. You can given an empty string "" if no tabs are required in the dialog.

Miscellaneous Methods

The following methods are available when importing the vcHelpers.Application library.

Name Return Type Parameters Description
copyProperties None vcComponent comp1, vcComponent comp2 Copies the properties of a component to another component.

The comp1 argument defines the component whose properties are copied.

The comp2 argument defines the component which gets the copied properties.
endMessage None String message Prints a given message to the Output panel and unblocks the application.
findCommand vcCommand String name Returns a command in the application matching the given name; otherwise returns None.
progressMessage None String message, Real fraction Prints a given message to the Output panel and updates the value of the progress bar based on a given fraction ranging from 0.0 to 1.0.

Generally, this is used to provide feedback to a user about the progress of one or actions.

This method does not unblock the application.
progressStdMessage None Real completed, Real total Displays the status of an operation based on a given amount of work completed in relation to the total amount of work.

This method does not unblock the application.
startMessage None String message Prints a given message to the Output panel.

Using this method, progressMessage() or progressStdMessage() will block the application, thereby preventing user interaction.

To unblock the application, use the endMessage() method.

Example. Create a non-modal dialog box with tabs

### first create a button property in a component, name it 'Button_1' and  
### then copy paste following script to test non-modal dialog box
from vcScript import *
from vcHelpers.Application import *
  
def button_event_1(arg):
  global diag
  diag = getDialog()
  
  par1 = diag.addProperty('Text 1',VC_STRING, None)    
  par2 = diag.addProperty('Text 2',VC_STRING, None)    
  par3 = diag.addProperty('Text 3',VC_STRING, None)
  par4 = diag.addProperty('Button', VC_BUTTON, button_event_1)
  
  par2_1 = diag.addProperty('Tab2::Text2_1',VC_STRING, None)    
  par2_2 = diag.addProperty('Tab2::Text 2_2',VC_STRING, None)    
  par2_3 = diag.addProperty('Tab2::Text 2_3',VC_STRING, None)    
  par3_1 = diag.addProperty('Tab3::Property1',VC_BOOLEAN, None)
  
  diag.Name = "Test non-modal Dialog"
  diag.GeneralTabCaption = 'Tab1'
  diag.showTabs()
  diag.show()
comp = getComponent()
button_ = comp.getProperty('Button_1')
button_.OnChanged = button_event_1

Example. Command to create a modal dialog box with tabs

from vcScript import *
from vcHelpers.Application import *
from vcCommand import *
 
cmd = getCommand()
 
def create_cmd_properties():
 
#Read command existing properties   
  props = cmd.Properties
 
  #First lets delete all the properties of the command   
  while(len(props)>0):     
    p = props.pop()     
    try:       
      cmd.deleteProperty(p.Name)     
    except:       
      pass
 
# Create some properties for Tab 1   
  par1 = addProperty(cmd,VC_STRING,'Text 1',True,False,False,'',None,'')   
  par2 = addProperty(cmd,VC_STRING,'Text 2',True,False,False,'',None,'')   
  par3 = addProperty(cmd,VC_STRING,'Text 3',True,False,False,'',None,'')
 
# For generating more Tabs just add properties with names as "Tab2::Property1","Tab3::Property2"...   
 
  par2_1 = addProperty(cmd,VC_STRING,'Tab2::Text 2_1',True,False,False,'',None,'')   
  par2_2 = addProperty(cmd,VC_STRING,'Tab2::Text 2_2',True,False,False,'',None,'')   
  par2_3 = addProperty(cmd,VC_STRING,'Tab2::Text 2_3',True,False,False,'',None,'')   
  par3_1 = addProperty(cmd,VC_STRING,'Tab3::Property',True,False,False,'',None,'')
 
# Method that displays the dialog waits until a button is pressed
def display_command_properties():   
  ok = displayPropertyDialog(cmd.Name,'Tabs Example', 'Tab 1')   
  if not ok:     
    print 'Aborted'     
    return False   
  return True
 
def first_State():   
 
#Call the method that creates the properties   
  create_cmd_properties()   
  display_command_properties()
 
cmd.addState(first_State)
