vcHelpers.Output

vcHelpers.Output provides different levels of output messages (info/warning/error/debug) for the owner component/command. The messages have the owner's name as a prefix, and they can optionally print the simulation time. The printing of different levels can be toggled on/off with methods or with bounded properties.

Methods

Name Return Type Parameters Description
info() None List of arguments, [Boolean simtime] Prints given positional arguments to output. To print simulation time (as a prefix), set simtime key argument to True, default is False.
warning() None List of arguments, [Boolean simtime] Prints given positional arguments to output. To print simulation time (as a prefix), set simtime key argument to True, default is False.
error() None List of arguments, [Boolean simtime] Prints given positional arguments to output. To print simulation time (as a prefix), set simtime key argument to True, default is False.
debug() None List of arguments, [Boolean simtime] Prints given positional arguments to output. To print simulation time (as a prefix), set simtime key argument to True, default is False.
setInfo() None Boolean Value Enable (True) or disable (False) info messages.
setWarnings() None Boolean Value Enable (True) or disable (False) warnings.
setErrors() None Boolean Value Enable (True) or disable (False) errors.
setDebug() None Boolean Value Enable (True) or disable (False) debug messages.
bindInfoProperty() Boolean String or vcProperty Bind a component/command property as a toggle to enable/disable info messages. Use the name of the property or the property instance as the argument.
bindErrorProperty() Boolean String or vcProperty Bind a component/command property as a toggle to enable/disable errors. Use the name of the property or the property instance as the argument.
bindWarningProperty() Boolean String or vcProperty Bind a component/command property as a toggle to enable/disable warnings. Use the name of the property or the property instance as the argument.
bindDebugProperty() Boolean String or vcProperty Bind a component/command property as a toggle to enable/disable debug messages. Use the name of the property or the property instance as the argument.
