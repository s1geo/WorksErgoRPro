vcProcessExecutor

Process executor is a behavior that holds and runs process routines (vcProcessRoutine). Each process routine is an implementation of a process. The execution order of the process routines is controlled by the parent process controller (vcProcessController).

Inherits: vcExecutor, vcBehaviour

Type constant: VC_PROCESSEXECUTOR

Properties

Name Type Access Description
ProcessController vcProcessController R Gets the associated process controller.
Processes List of vcProcessRoutine R

Gets all process routines in this executor.

Returns None if the executor does not have a program.
TransportNode vcTransportNode RW

Gets the associated transport node that this executor’s processes use to receive and send product instances.

Setting this property also sets the ProcessExecutor property on the new transport node, and clears the property from the old transport node, if there was one.

Methods

Name Return Type Parameters Description
addProcess vcProcessRoutine String name

Creates a new process routine and adds it to this executor’s program.

The routine name has to be unique within this executor’s program.

Returns None if the executor doesn’t have a program.
deleteProcess None vcProcessRoutine routine Removes the given routine from this executor’s program and deletes it.

Examples

Example. Changing process statement properties dynamically (runtime) based on connected flow groups

# a script in "Process Node" component
from vcScript import *
# get the first process executor (vcProcessExecutor) in the component
proc_executor = getComponent().findBehavioursByType(VC_PROCESSEXECUTOR)[0]
def OnStart():
  global group_index_iter
  global first_process_name
  global groups
  # use this iterator as the index for selecting flow group
  group_index_iter = 0
  # get the name of the first process (vcProcessRoutine)
  first_process_name = proc_executor.Processes[0].Name
  # collect all flow groups (vcProcessFlowGroup) that have an incoming link to the process
  # to a global list
  groups = []
  transport_node = proc_executor.TransportNode
  for link in transport_node.TransportLinks:
    if link.Destination == transport_node:
      groups.append(link.SupportedGroup)
def statement_changed(stmt, is_immediate):
  global group_index_iter
  if stmt.Type == VC_STATEMENT_TRANSPORTIN and stmt.ParentRoutine.Name == first_process_name:
    # set statement properties: accept only from the connected flow groups, one-by-one
    stmt.AcceptAllProductTypes = False
    flow_group = groups[group_index_iter] # select next flow group from the list
    stmt.AcceptedFlowGroups = [flow_group]
    group_index_iter += 1
    if group_index_iter == len(groups):
      group_index_iter = 0 # reset iterator
# this event is raised just before executing any statement in any process belonging to the executor
proc_executor.OnPreExecuteStatement = statement_changed
