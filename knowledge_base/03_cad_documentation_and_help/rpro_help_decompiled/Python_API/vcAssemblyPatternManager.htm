vcAssemblyPatternManager

vcAssemblyPatternManager is used to create, modify, and delete assembly patterns (vcAssemblyPattern).

Properties

Name Type Access Description
Patterns List of vcAssemblyPattern R List of all assembly patterns.

Methods

Name Return Type Parameters Description
createPattern vcAssemblyPattern String name Creates a new assembly pattern with given name. Names must be unique.
deletePattern None String name, vcAssemblyPattern pattern Deletes the pattern given explicitly, or deletes pattern by name.
clonePattern vcAssemblyPattern String name, vcAssemblyPattern pattern Creates a copy of the pattern given explicitly, or found pattern with given name.
findPattern vcAssemblyPattern String name Returns an assembly pattern with given name, if it exists.

Events

Name Parameters Description
OnPatternAdded vcAssemblyPattern Triggered when a pattern has been added to Pattern Manager.
OnPatternRemoving vcAssemblyPattern Triggered when a pattern is being removed from Pattern Manager.
