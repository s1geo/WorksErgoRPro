vc3DIcon

vc3DIcon is a layout item used for rendering sets of Frame features (vcFrameSet), path points (vcMotionPath), and path objects (vcPathObject) as 3D icons in a layout.

Inherits: vcLayoutItem

Properties

Name Type Access Description
Geometry vcGeometryContainer R Gets the container used by the icon to store its geometry.
Layer vcLayer RW Defines the layer the icon belongs to in the 3D world.
Name String RW Defines the icon's name.
Uri String RW Defines the URI of the icon file.
