vcProcessFlowState

FlowState indicates an exact location in the product flow. Used in Product’s CurrentProcessFlowState.

Properties

Name Data type Access Description
FlowStep vcProcessFlowStep RW Specifies ProcessFlowStep the product is in currently.
GroupId String RW Specifies ProcessGroup inside the FlowStep the product is in currently.
Routine vcProcessRoutine RW Specifies the specific ProcessRoutine the product is in currently.
