Modules

A module is a file containing Python definitions and statements. The name of the file (without the .py or .pyc) extension is used as the name of the module. Definitions from a module can be imported into other modules using the import statement. A module can contain executable statements as well as function definitions. These statements are intended to initialize the module. They are executed only the first time the module is imported somewhere.

Standard Modules

Python comes with a library of standard modules, described in Python Library Reference, available at http://www.python.org. The integrated Python also includes main application framework specific modules or API such as vcScript, vcApplication and vcKinematics. These and other API modules are described in the Python API reference guide.

3rd Party Modules

Common 3rd party modules (TCP/IP communication, ODBC, Win32, COM, TkInter) are also installed with the product.

If you use any extensions that are not included in the product installer, you must copy the extension package into the main application's Python library directory, usually located at C:\Program Files\[Provider]\[Product Name]\Python.

Python scripts are copied to the lib\ subdirectory. Python assemblies can be copied to the DLLs\ subdirectory.

Modules are imported using the import statement with the module name. The definitions from a module can then be accessed by prefixing the module name to the function name.

# Fibonacci numbers module
# write Fibonacci series up to n
def fib(n):
  a, b = 0, 1      
  while b < n:          
  print b,          
  a, b = b, a+b
  
# return Fibonacci series up to n
def fib2(n):
  result = []
  a, b = 0, 1
  while b < n:
    result.append(b)
    a, b = b, a+b
  return result

Example. Import and use a module

import fibo
fibo.fib2(8)

A user can also import specific or all definitions from a module, after which they can be accessed directly.

Example. Import all definitions and use a module

from fibo import *
fib2(8)

Methods

Python has a remarkably simple, readable and maintainable syntax, which makes it easy to learn for the application engineer, while at the same time powerful enough for the software developer. The following is a brief overview of the syntax used in Python.

Note: Python uses indentation for conclusion of logical sequences so there are no end-for, endif or endwhile type statements.

Built-in Types (objects)

Python supports the following built-in types:

  • Numbers (integer, floating point and complex)
  • Strings
  • Lists
  • Dictionaries
  • Files

Variables

Variables do not have a type and users are not required to declare them. Variables are initialized when you first use them. Assignment is done using the = operator.

Example. Assign value with = operator

a=5
a=6.7

A user can assign the same value to multiple variables.

Example. Assign same value to multiple variables

x=y=z=8

A user can also assign multiple values to several variables.

Example. Assign multiple values to several variables

x=y=z=8

Expressions

Python uses infix notation with standard order of evaluation (i.e. * and / before + and -) with the order of evaluation changed using parenthesis.

Supported operations include but not limited to:

  • Arithmetic
    <  -  +  >
  • Logical
    and  or  not
  • Bitwise
    &  |  ^
  • Membership
    in
  • Shifts
    <<  >>
  • Comparison
    <  ==  !=  <=  >=

Example. Expression

2*(5-3)

Statements

Python does not use an explicit end of statement token; the end of the line marks the end of the statement. A semi-colon (;) is used as a statement separator for writing more than one statement on a line.

Example. Statements with statement separator

a=5
b=a+8
a=5; b=a+8

Statement Blocks

Block markers are grouped using indentation. That is, statements on the same indentation level belong to the same statement group or code block. Indentation of statements and code can be referred to as nesting statements.

Example. Python

a=5
b=a+8
c = b-3

Example. BREAK

a = 0
 
#Breaks the innermost loop.
#Execution continues with the statement following the loop (else statements are not executed)

Example. CONTINUE

#print all numbers in range except 3

  if i == 3:
