vcPathObjectParameterNode

vcPathObjectParameterNode is a node used to store any kind of data related to a location, for example calibration data, and is not part of a path object's trajectory.

Inherits: vcPathObjectNode

Properties

Name Type Access Description
PositionMatrix vcMatrix RW Defines the position matrix of parameter node in World coordinate system or in relation to a reference node.
ReferenceNode vcPathObjectReferenceNode Rw Defines a reference node in path object used for defining location of parameter node.
