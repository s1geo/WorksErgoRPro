vcBaseContainer

vcBaseContainer is a container of Frame features used as base frames.

Inherits: vcBehaviour

Properties

Name Type Access Description
Bases List of vcBaseFrame R Gets a list of all base frames in container.

Methods

Name Return Type Parameters Description
addBase vcBaseFrame None Adds a new base frame to container.
removeBase None vcBaseFrame base Deletes a given base from container.

Examples

Example. Create a Base Container behavior and base frames

from vcScript import *
 
#create Base Container
comp = getComponent()
foo = comp.createBehaviour(VC_BASECONTAINER, 'Example')
 
#create Base Frame
bar = comp.findBehaviour('Example')
bar.addBase()
