Property Condition

A PropertyCondition is a requirement statement and that allows you to create a requirement based on a property value.

Select first a component and then select either its property by leaving Selected behavior Null, or alternatively, select component's behavior to select behavior property.

Properties

Name Description
Selected component Select the component in the 3D world.
Selected behavior A list of behaviors in the Selected Component. Select the behavior to select its property, otherwise select Null.
Selected property

If Selected behavior is Null, the list is showing component properties of Selected Component.

Otherwise, listed properties belongs to Selected behavior.

Condition expression

Your condition to evaluate.
