Wait Transport

A WaitTransport statement allows you to wait for one or more transport operations started with StartTransportIn or StarTransportOut statements to complete. The transport operations are identified by the ProductVariableName.

Note: The variable is in undefined state between the execution of StartTransport and WaitTransport statements and therefore it should not be used for anything else before WaitTransport has completed. After the WaitTransport statement the variable contains the arrived Products.

Properties

Name Description
ProductVariableName Variable name of a product that is to be transported in or out.
