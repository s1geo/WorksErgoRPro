Cell Graph

The Cell Graph panel provides an outline of the current layout in 3D world and options for selecting and editing listed items.

1. Show/Hide Invisible Components in 3D World
2. Search for Components
3. Type of Component
4. Selected Components
5. Component Name
6. Lock Editing for Component Type
7. Filter Types for Search
8. Visibility for Component Type
9. Lock Editing and Visibility for Component
