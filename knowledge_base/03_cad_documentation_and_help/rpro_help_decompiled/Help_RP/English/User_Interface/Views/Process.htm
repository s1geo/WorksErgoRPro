Process

The Process view allows you to define processes, product types and their flow.

Access

To access the Process view:

  • Click the Process tab.

Panels

The Process view shows, by default, the following panels:

  • Cell Graph for listing, selecting and editing components in a layout
  • Properties for reading and writing properties of selected objects in a layout.

Context

The context of the Process view is process modeling.

You can:

    • Add flow groups.

• Create and edit product types.

    • Preview processes and edit their routines.

    • Select flow groups and edit their process steps.

    • Select flow groups and edit their transitions of products to different locations and processes.

Commands

By default, the following commands are shown in the Ribbon when you click the Process tab.

Name Description
Always Snap Turns on/off the automatic snapping of a selected object along an axis or plane at intervals when using the manipulator.
Automatic Size Turns on/off the automatic calculation of intervals for snapping a selected object along an axis or plane when using the manipulator.
Copy Copies the current selection to the clipboard.
Delete Deletes the current selection.
Filter Transport Links Filters the visibility of the transport links in the 3D viewport. When one process step is selected, shows valid paths from previous process step and to the next process step. When multiple process steps are selected, shows only the valid paths between the process steps.
Flow Opens/closes the Process flow editor view and panel to edit process steps and their transitions.
Move Allows a selected object to be moved along an axis or plane, rotated around an axis, and snapped and aligned to a point in 3D world.
Paste Adds the contents of clipboard to active area or field of workspace depending on data type.
PnP Allows the pointer to plug selected components into other components to form physical connections.

Note: A selected component must have an interface, otherwise it cannot be plugged into any component. Other components must have compatible interfaces, otherwise selected components will not plug into them. Components that are plugged into one another may or may not be attached to one another.

Processes Opens/closes the process configuration view, where you can select and edit processes.
Products Opens/closes the Product type editor for adding and editing flow groups and product types.
Restore Windows Restores the workspace of current view to its default setting.
Select Allows for direct and indirect selection of components in the 3D world using listed commands.

Rectangular selection
Select by drawing a selection box.

Free-form selection
Select by drawing a selection path to form a closed loop.

Select all
Selects all components.

Invert selection
Forms a new selection of every component not in current selection.

Show

Displays a list of panels that can be shown/hidden from the current view of workspace.

Size Defines the interval for snapping a selected object along an axis or plane when using the manipulator.
