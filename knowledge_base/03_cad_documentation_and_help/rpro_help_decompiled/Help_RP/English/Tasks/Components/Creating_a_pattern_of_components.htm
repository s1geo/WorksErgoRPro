Creating a pattern of components

Selected objects in a simulated environment can be cloned to form an angular or a linear pattern of components.

  1. In the scene, select the object you want to clone.
  2. On the Home tab, in the Tools group, click Pattern.
  3. In the Pattern task pane, edit settings for defining the pattern. In the scene, a preview of pattern is shown by bounding boxes.
    • To clone component along an axis, select Mode to Linear Pattern. Then define the axis to Pattern Along.
    • To clone component around an axis, select Mode to Angular Pattern. Then define the axis to Pattern Around. To offset the pattern axis, define Offset Along to another axis or vector and then define the Offset Distance or Offset Vector.
    • Define Angular or Linear Step between the components in the pattern.
    • Define Count as the total amount of components in the pattern.
  4. Click Apply. The pattern of components is created and all the components are selected.
  5. Click Close or create another pattern.

Note: If the selected component is attached to a parent, all the cloned components will be also attached to the same parent.
