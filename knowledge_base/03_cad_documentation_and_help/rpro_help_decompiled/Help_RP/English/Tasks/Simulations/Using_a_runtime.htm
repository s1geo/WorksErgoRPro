Using a Runtime

A runtime allows you to define how long execute a simulation in the 3D world.

  1. In the 3D world, on the Simulation controls, click Settings.
  2. In Clock Display Mode, click the desired time format.
  3. In Simulation Run Time, do one of the following:
    • To remove a time restriction for a simulation, click the Infinity symbol.
    • To define a time restriction for a simulation, click Custom, and then type and/or use the Up and Down arrows in each cell to set the desired time value.
