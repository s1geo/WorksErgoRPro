Streaming Animation

It is possible to stream the 3D scene in live connection to a client viewer.

Step 1. Enable Animation Streaming

The Animation Streaming feature can be turned on/off using a backstage option.

  1. Click the File tab, and then on the Navigation pane, click Options.
  2. On General, define the Animation Streaming settings:
    • select the Enabled check box.
    • define the Port number for streaming. The default is 7000.
  3. Click Ok.
  4. Restart your R-Pro 2.1 product.

Step 2. Run R-Pro Experience

R-Pro 2.1 Experience is a separately installed application. For desktop installation, you can download it on R-Pro 2.1 website. For mobile devices, visit App Store (iOS) or Google Play Store to download it.

  1. Launch R-Pro Experience.
  2. Select the Advanced Settings check box.
  3. Define Streaming Host IP Address. If local host, use 127.0.0.1.
  4. Define Streaming Port as the same than defined in the backstage option.
  5. Select Desktop or VR mode (only for desktop viewer).
  6. Select Animation.
  7. From drop-down menu, select <Stream - 127.0.0.1:7000> where 127.0.0.1 is Streaming Host and 7000 is Streaming Port.

When streaming is active and a client is connected, the Play/Pause button of the Simulation Control panel is blue.
