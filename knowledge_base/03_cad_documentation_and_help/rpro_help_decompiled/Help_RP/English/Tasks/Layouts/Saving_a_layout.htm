Saving a Layout

A layout allows you to save the location, connections and property values of components in the 3D world. A layout also stores your view of a scene and any layout items in the 3D world and drawing area.

  1. In the 3D world, adjust the view to define the preview image of the layout for when it is displayed in the eCatalog panel.
  2. Click the File tab, and then on the Navigation pane, click Save As.
  3. Save the file.

Contents of a saved layout

A saved layout includes everything except the geometry features of components that have been added to the layout e.g., from the eCatalog. A layout references the VCID (unique identifier) of the included components, and when opening the layout, a search is carried out for component geometry within the available eCatalog sources.

When you import geometry from CAD files (see Import Model Settings) it will be saved with your layout. And if you save that geometry as a component in your eCatalog panel Collections view e.g., your My Models folder, it will still be saved with your layout.

When should I enable Include Components?

  • To ensure that any components you add from the eCatalog are saved with the layout. This is especially relevant if, in the future, any components you have added from the eCatalog are no longer accessible or have been modified.
  • As a general rule, if you save a layout to share it with another R-Pro 2.1 user, or are backing up your saved layout files, then you should always enable Include Components. Doing so may increase your file size but it will help to prevent issues when opening any saved layouts.

And Include Component original path will assist with finding any missing components by displaying its file path in the Output panel.
Note: Before enabling this option you should check that displaying a file path will not expose any confidential information.
