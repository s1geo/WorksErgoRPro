Backward Compatibility

If you are upgrading layouts made with an older version of the Stäubli add-on, refer to the following information about backward compatibility.

Issue Explanation
The new add-on uses the same configuration persistence format as the old add-on. This means old VCM layout files with Stäubli add-on configuration can be opened in R-Pro 2.1.

You cannot make changes to those layouts and save them in VCM format. You can, however, save them in rpro format.

Old format for robot executor and program need to be upgraded to avoid limitations. This means you can still connect to an emulator, map a robot, and edit existing I/O mappings without upgrading the robot.

In order to use a simulation mode other than Idle, add new I/O mappings, and post process a robot program, you will need to upgrade the executor of the robot program.
