Edit Statements in a Robot Program

Statements in a robot program can be edited using the Properties panel.

    1. Click the Program tab, and then use the Jog command to select the robot you want to program in the 3D world.
    2. In the Program Editor panel, Subprograms pane, select a routine to list its statements.
    3. In the subroutine, select the statement you want to edit.
    4. Do one or more of the following:
      • To edit the properties of a selected statement, in the Properties panel, edit one or more properties.
      • To copy and paste a selected statement, on the Program tab, in the Clipboard group, click Copy, and then click Paste.
      • To delete a selected statement, press Delete.
