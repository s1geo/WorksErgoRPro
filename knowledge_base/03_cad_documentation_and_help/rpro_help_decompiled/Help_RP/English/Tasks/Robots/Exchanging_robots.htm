Exchanging Robots

A robot can be exchanged with another robot in the 3D world to switch locations and programs. When exchanging robots, a compatible robot will be highlighted yellow in the 3D world to indicate it can be exchanged with the selected robot.

  1. In the 3D world, select a robot.
  2. On the Program tab, in the Tools group, click Exchange Robots.
  3. In the 3D world, click a compatible robot that you want to exchange with the selected robot. The highlight color of a compatible robot that you click will change from yellow to green to confirm that robot will be exchanged with the selected robot.
  4. In the Exchange Robots task pane, click Apply.
