Creating Statements in Robot Program

A statement is a command executed by a robot in its program.

Statements in a robot program are contained in subroutines and executed in order one after the other. Explicit variables and other properties of a robot, including I/O ports, can be used to define statements and conditions for program execution.

  1. Click the Program tab, and then use the Jog command to the select robot you want to program in the 3D world.
  2. In the Program Editor panel, create or select a subroutine to contain statements.
  3. If you are prompted to upgrade the executor of the selected robot, click Upgrade Rsl executor, and then go back to Step 2.

  4. In the Statments toolbar, do one of the following:

    • To create a point-to-point motion to the current position of robot, click Joint Motion Statement. *
    • To create a linear motion to the current position of robot, click Linear Motion Statement. *
    • To update a tool frame during a simulation, click Define Tool Statement, and then define values for a tool frame set by that statement.
    • To update a base frame during a simulation, click Define Base Statement, and then define values for a base frame set by that statement.
    • To update a selected PTP, LIN or PTPHome statement in the robot program, click Touch-up.
    • To call a subroutine, click Call Sequence Statement, and then define the subroutine called by that statement.
    • To end the execution of a subroutine, click Return Statement.
    • To end the execution of a loop, click Break Statement.
    • To set a loop to execute from its next iteration, click Continue Statement.
    • To create a conditional statement, click If Statement, and then define the condition for executing statements nested in THEN or ELSE group of that statement.
    • To create a loop, click While Statement, and then define the condition for executing statements nested in that loop.
    • To synchronize program execution with other components, click Program Synchronize Statement, and then define the message and components to synchronize and whether or not the statement will wait until all components in the sync send the correct message before continuing program execution.
    • To delay the execution of a subroutine, click Delay Statement, and then define the delay in seconds for that statement.
    • To stop the execution of a subroutine, click Halt Statement, and then define if that statement will reset the simulation.
    • To leave comment, click Comment Statement, and then define the comment for that statement.
    • To print and display feedback, click Print Statement, and then define the message for that statement.
    • To wait for an input signal to have specific value, click Wait for Binary Input Statement, and then define the value and port number to wait for in that statement.
    • To set the value of an output signal, click Set Binary Output Statement, and then define the state and port number to set for that statement.
    • To generate a path of positions along an edge or curve, click Add Path.* This displays a Select Curve task pane for picking and editing a path of points, for example seams in a workpiece. Generated points are linear motion statements and nested in a Path statement.

    * TIP: Alternatively, you can also use the actions in the Teach Overlay Menu. See Fast Robot Teaching
