Visualizing the tool detection volume

DetectionVolume property visualizes the detection volume of the selected tool TCP from a robot. DetectionVolume shows which product(s) are grasped to a robot when utilizing grasp/release signals 1-16.

To activate the Detection Volume, do the following:

  1. Click on the robot in the 3D world.
  2. Under Properties, select the SignalActions tab.
  3. Activate the ShowDetectionVolume property.
    • Selecting DetectionVolumeGeometry, the visualization would be of type Box or Line.
    • DetectionVolumeTool displays all the tool TCPs. You can select a tool TCP from the drop-down menu.
    • DetectionVolume displays the visualization of the selected tool TCPs detection volume. The X, Y, Z coordinates are side lengths in millimeters for the detection volume that has the tool TCP as a center point.

Notes:

  • DetectionVolume properties are independent of the Grasp/Release properties in Actions Configuration and they are only for visualization purposes. For example, changing the DetectionVolumeTool and DetectionVolume values from SignalActions does not alter the DetectionVolumeSize and Using tool in Actions Configurations and vice versa.
  • The detection volume is not rendered while the simulation is running.
