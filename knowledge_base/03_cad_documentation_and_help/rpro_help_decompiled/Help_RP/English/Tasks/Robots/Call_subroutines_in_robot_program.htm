Call Subroutines in Robot Program

In order for a subroutine to be executed, it needs to be called by either the Main routine or another subroutine that is executed in a robot program.

  1. Click the Program tab, and then use the Jog command to the select robot you want to program in the 3D world.
  2. In the Program Editor panel, select the subroutine that you want to use to call another subroutine.
  3. On the Statements toolbar, click Call Sequence Statement.
  4. In the Properties panel, set Routine to the subroutine you want to be called by that statement.
