Create Subroutines in Robot Program

A subroutine contains a sequence of statements that can be executed by a robot. Subroutines need to be called in the Main routine of a robot program either directly or by another subroutine in order to be executed during a simulation.

    1. Click the Program tab, and then use the Jog command to select the robot you want to program in the 3D world.
    2. In the Program Editor panel, Subprograms pane, click the PLUS SIGN.
