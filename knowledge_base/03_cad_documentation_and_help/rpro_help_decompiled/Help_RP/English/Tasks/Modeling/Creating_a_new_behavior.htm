Creating a New Behavior

A behavior is an action or set of actions that a component can perform before or during a simulation.

  1. Either create or select a component in the 3D world.
  2. Click the Modeling tab, and then in the Component Graph panel, Component Node Tree, select a node. This defines the node containing any new behavior you are about to create in the component.
  3. On the Modeling tab, in the Behavior group, click the Behavior arrow, and then click the type of behavior you want to create in the component.
