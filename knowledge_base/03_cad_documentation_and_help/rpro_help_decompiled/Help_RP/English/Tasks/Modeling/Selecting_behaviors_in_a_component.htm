Selecting Behaviors in a Component

You need to use the Component Graph panel to select behaviors in a component.

  1. In the 3D world, select a component or one of its features.
  2. If you did not select a feature, click the Modeling tab, and then in the Component Graph panel, Component Node Tree, expand one or more nodes.
  3. If behaviors are not listed below nodes, select the Behaviors check box.
  4. Expand one or more Behaviors lists to find the behavior you want to select, and then select the behavior. An alternative is to search for a behavior by name using the Search box.
