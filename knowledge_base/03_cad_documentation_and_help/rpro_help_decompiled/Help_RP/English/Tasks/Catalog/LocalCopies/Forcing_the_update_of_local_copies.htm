Forcing the Update of Local Copies

A local copy is automatically synced with its source when there is an active connection. This means new files added to a remote source would be automatically checked for and downloaded by the eCatalog panel. In some cases, you may want to force update a local copy with its source if there was a connection issue.

  1. In the eCatalog panel, access the Collections view.
  2. Click the PLUS SIGN, and then click Edit Sources.
  3. In Sources, find the remote source you want to edit.
  4. Clear the source's Keep local copy check box, and then select the check box again.
