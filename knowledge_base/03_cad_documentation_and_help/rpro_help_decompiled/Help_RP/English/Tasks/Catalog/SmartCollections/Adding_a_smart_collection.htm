Adding a Smart Collection

You can add a new smart collection in the eCatalog panel.

  1. In the eCatalog panel, access the Collections view.
  2. Click the PLUS SIGN, and then click Add Smart Collection.
  3. In the middle of New Smart Collection, use the drop-down menus to define the first filter condition, for example Collection Is All Models.
  4. Do one or all of the following:
    • To add another filter, click the PLUS SIGN and then use the drop-down menus to define the new logical filter condition, for example And Type Is Conveyors.
    • To define a group, at the bottom of New Smart Collection, use the drop-down to define the group, for example Manufacturer will group matching items by manufacturer.
    • To add a subgroup, at the bottom of New Smart Collection, click the PLUS SIGN, and then use the drop-down menu to define the new subgroup.
  5. Click Save.
