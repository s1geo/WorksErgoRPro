Simple

Action Function

CTRL+N Clears the 3D world layout.
CTRL+O Opens a file as a layout in 3D world.
CTRL+S Saves the current layout to existing or new file.
CTRL+V Pastes the content of clipboard to the active area.
CTRL+ALT+J Prints product version information to Output panel.

 Play or pause simulation.

 Move to the next field in the Properties panel.

Navigation

Action Function
CTRL+F Fills view with all components in 3D world.
CTRL+ALT+F Fills view with selected components in 3D world.
Point at object in 3D world, hold down SHIFT, and then right-click Centers view on point of object in 3D world, that is sets the center of interest (COI) of camera.
Point to 3D world, hold down right mouse button, and then drag the pointer Orbits the camera.
Point to 3D world, hold down left and right mouse buttons, and then drag the pointer Pans the camera.
Point to 3D world, rotate mouse wheel forward/backward

-or-

Point to 3D world, hold down SHIFT and the right mouse button, and then drag the pointer up/down

 Zooms in/out the camera.

Object Manipulation

Action Function
Hold down CTRL, and then left-click an object in 3D world Adds or removes an object from current selection.
Point to 3D world, hold down CTRL and the left mouse button, and then drag the pointer Draws a selection box or path for selecting objects in 3D world.
Hold down CTRL, and then double-click a component in 3D world Duplicates a component, thereby creating a copy of it in 3D world.
Hold down SHIFT, point to geometry of selected object in 3D world, and then drag the pointer to align geometry point (red torus), and then release SHIFT

-and-

Hold down SHIFT, point to geometry of same object, and then drag the pointer to align geometry along a vector (green torus), and then release SHIFT

-and-

Hold down SHIFT, point to geometry of same object, and then drag the pointer to align geometry along another vector (blue torus), and then release SHIFT

 Aligns a selected object using one to three vectors. Alignment vectors are indicated by yellow arrows and with the head of each vector a colored torus. Dragging the head of a vector allows you to realign the object but will undo any following alignments. For example, dragging the green torus will cancel the alignment to blue torus but not that of the red torus.

Note: Shortcut uses 30 pixel threshold, so you may need to move pointer a bit to execute action.
While dragging an arrow handle of manipulator for a selected object in 3D world, hold down CTRL, and then point to geometry to snap axis to that position Snaps a selected object to same position of geometry in one of three axes. For example, floor object can be snapped to same height of elevated object in Z-axis.
While dragging torus (origin) of manipulator for a selected object, hold down SHIFT and hover over geometry Snaps object to geometry centers, for example edge midpoints and face centers.
While dragging torus (origin) of manipulator for a selected object, hold down CTRL Allows object to be moved freely in 3D world without snapping to other objects.

Interactive Picking

Action Function
While taking a measurement, hold down CTRL and hover over geometry Picks center point of geometry, for example edge midpoints and face centers.
While snapping a selected object, hold down CTRL and hover over geometry Picks center point of geometry, for example edge midpoints and face centers.

Robot Teaching

Action Function
When using curve selection tools, hold down SHIFT to trim curve while teaching a robot path Trims path to selected point, thereby removing any following points from path and trimming its length. For example, curve with length of 200mm is selected, and then curve point at 100mm is selected to trim curve to that point.
When using curve selection tools, hold down CTRL to remove curve segment while teaching a robot path Removes a curve segment from path. For example, four edges are selected, and then one edge is removed from path leaving three curve segments.
When using curve selection tools, hold down ALT to flip curve normal while teaching a robot path Flips the normal of curve segment points, which can be verified by visualizing curve points of path.

Geometry Editing

Action Function
While dragging a feature to another feature or node in the Component Graph panel, hold down SHIFT With SHIFT, the position of the feature would stay the same in the 3D world. Without SHIFT, the 3D position of the feature is retained relative to its parent.
