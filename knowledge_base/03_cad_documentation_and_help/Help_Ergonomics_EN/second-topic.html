Installation

Software requirements

The R-Pro Ergonomics product is designed to work on the basis of the Rational Production (R-Pro) software - https://r-pro.digital/. To use it, you must have the R-Pro platform installed and configured, which provides the necessary system resources and functions. Before starting work, make sure that you have the current version of the R-Pro software installed.

Installation procedure

Run the Ergonomics_installer.exe installer and install the add-on.

To activate a local license, find the License Settings folder in the R-Pro folder, run license_wizard.exe. Click the License activation -> On this button, enter your license key in the window that appears. The product is activated, you can start working.

To activate a network license, contact your system administrator.
