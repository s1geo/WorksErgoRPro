## 1. Введение и Методология Исследования

Настоящий аналитический отчет представляет собой всестороннее инженерное вскрытие визуального, интерактивного и биомеханического поведения аддона **Work(s) Ergo**, представленного на официальном YouTube-канале создателя `@idkfa3` (Mustafa Kamal).

В отличие от стандартных презентационных материалов, данные 28 видеороликов суммарным хронометражем более 11 минут документируют **реальное взаимодействие инженера с 3D-сценой в Visual Components**, раскрывая:
1. Конкретные приемы манипулирования объектами (Snapping, Coordinate Alignment, Parenting).
2. Поведение кинематического решателя без ручной настройки углов сочленений (Zero Manual Joint Posing).
3. Интерактивные 3D-контроллеры в сцене (Floor Interact Gizmos).
4. Внутрисценические HUD-дисплеи (Body Map Whiteboard, Footprint COP Diagrams, MultiPose Toolbar).
5. Прикладные биомеханические алгоритмы (LM-MMH, Above-Shoulder, HandPak, Body Bracing, Straight Legs).

Цель настоящего документа — сформировать исчерпывающий свод инженерных спецификаций для воспроизведения и превосходства функционала Work(s) Ergo в отечественной среде **Р-Про v2.2.2** на базе локального C# / WPF / Python ядра.

### Видео 01: `1TK7Z2mKARo` — 01 - Floating Hands and MultiPose
* **ID:** `1TK7Z2mKARo`
* **Длительность:** 42 секунды
* **Ссылка:** [YouTube: 01 - Floating Hands and MultiPose](https://www.youtube.com/watch?v=1TK7Z2mKARo)

#### 1. Контекст сцены
Промышленный сборочный участок: стол с установленным станочным приспособлением и технологический лоток с деталями. Манекен работника расположен перед рабочей поверхностью.

#### 2. Механика 3D-взаимодействия
* Инженер выделяет в 3D независимые целевые узлы кистей рук (`LeftHandTarget`, `RightHandTarget`).
* Используется нативный инструмент Visual Components **Snap**:
  - Активируется флаг **`Set Orientation = True`**.
  - Параметр **`Align Axis`** строго выставляется в **`'-X'`** (нормаль ладони совмещается с нормалью контактной поверхности детали).
* В режиме **Interact** пользователь кликает по **Большому Желтому Цилиндру** на напольном контроллере.

#### 3. Поведение DHM
* **Zero Manual Joint Posing:** инженер не вращает ни одного сустава. Решатель InteliPose автоматически вычисляет углы сгибания коленей, таза, поясницы, шеи и рук.
* Перебор пула решений: каждое нажатие на желтый цилиндр циклически активирует альтернативную конфигурацию тела из тысяч найденных (варьируя угол отведения локтей, наклон торса и положение центра тяжести).

#### 4. Отображение UI / HUD
* Напольная зеленая табличка с тиснением `Work(s) Ergo` отображает текущий балл DCR и название активной позы.
* Плавающий тулбар в 3D с миниатюрами поз.

#### 5. Инженерные требования для Р-Про v2.2.2
* Реализовать отдельные дочерние узлы `LeftHandTarget` и `RightHandTarget` в компоненте `WorksErgoWorker.rpro`.
* Обеспечить калибровку локальной СК кисти: ось `-X` направлена перпендикулярно ладони наружу.
* Внедрить генератор пула поз InteliPose и обработчик клика по желтому цилиндру в режиме взаимодействия.

### Видео 02: `0bh-dkYO8WU` — 02 - Copy and Paste
* **ID:** `0bh-dkYO8WU`
* **Длительность:** 38 секунд
* **Ссылка:** [YouTube: 02 - Copy and Paste](https://www.youtube.com/watch?v=0bh-dkYO8WU)

#### 1. Контекст сцены
Многопостовая конвейерная линия сборки с несколькими одинаковыми технологическими постами и защитными барьерами.

#### 2. Механика 3D-взаимодействия
* Выделение манекена и нажатие стандартных комбинаций `Ctrl+C` / `Ctrl+V`.
* Тестирование свойства **`Attach Hands?`**:
  - При `True` кисти перемещаются вместе с манекеном на новый пост.
  - При `False` кисти остаются зафиксированными на CAD-детали, а манекен позиционируется относительно них.
* Назначение барьеров через выпадающий список: клонированный манекен связывается с `Barrier #2` и `Barrier #3`.

#### 3. Поведение DHM
* Клонированный экземпляр манекена полностью автономен: имеет собственный кинематический решатель, персональный расчет DCR и независимые векторы нагрузок.

#### 4. Отображение UI / HUD
* Панель свойств компонента мгновенно подхватывает новые имена барьеров.
* Плавающий тулбар MultiPose дублируется для второго манекена со своими иконками поз.

#### 5. Инженерные требования для Р-Про v2.2.2
* Корректная обработка события `OnClone` / дублирования в `WorksErgoWorker`: генерация уникальных внутренних GUID для целевых фреймов кистей, предотвращение перекрестных ссылок на геометрию оригинала.

* **Длительность:** 33 секунды

#### 1. Контекст сцены
Операция контроля качества и сборки внутри ограниченного замкнутого объема (каркас шкафа управления / ниша кузова) с ребрами жесткости и перегородками.

#### 2. Механика 3D-взаимодействия

* Создать вспомогательный видовой экран (Picture-in-Picture или отдельное WPF-окно) с привязкой камеры к узлу `Head_Eyes`.

### Видео 05: `84i_Tnt5JCw` — 05 - Hand Tasks, Force and Direction
* **ID:** `84i_Tnt5JCw`

Участок ручной механической обработки: рабочий удерживает пневматический инструмент и прикладывает усилие подачи.

#### 2. Механика 3D-взаимодействия

  - `03 Push Palm/Fist`
  - `04 Pinch (Precision / Lateral)`

  - Синяя стрелка — левая рука.

* Интегрировать классификатор 23 захватов HandPak в C# ядро.
* Реализовать 3D-векторные манипуляторы усилия (направляющие стрелки) с привязкой к СК кистей.
* Внедрить нейросетевую модель AFF (LaDelfa & Potvin, 2017) для оценки изометрической силы руки под любым пространственным углом.

### Видео 06: `-5CGQ5sS9YQ` — 06 - Body Bracing
* **ID:** `-5CGQ5sS9YQ`
* **Длительность:** 17 секунд
* **Ссылка:** [YouTube: 06 - Body Bracing](https://www.youtube.com/watch?v=-5CGQ5sS9YQ)

#### 1. Контекст сцены
Глубокий рабочий стол с технологической тарой, расположенной на значительном удалении ($> 700\text{ мм}$ от края столешницы).

#### 2. Механика 3D-взаимодействия
* Переключение параметра **`Body Bracing`** в выпадающем списке свойств:
  - `None` (свободное стояние на ногах).
  - `On Lower Extremities` (упор бедрами/коленями в край стола).
  - `On Torso` (опирание грудью/животом на опорную поверхность).
* Активация режима визуализации `Show Analysis Tools?`.

#### 3. Поведение DHM
* В режиме `None`: при попытке дотянуться до далекой коробки Центр Давления (COP) выходит за пределы контура стоп. Поза бракуется решателем как травмоопасная (падение вперед).

   - Интерактивные манипуляторы вытягивания граней в режиме `Interact`.
3. **`MediaTablet.rpro`:**
   - Планшет для отображения цеховых фото- и видеоматериалов для валидации позы.

* `Biomechanics/InteliPoseSolver.cs`: кватернионный IK-решатель и генератор пула поз.

* `Biomechanics/LumbarSpineJagerChaffin.cs`: 3D-расчет сжатия L5/S1 с поправкой на наклон $34^\circ$.
